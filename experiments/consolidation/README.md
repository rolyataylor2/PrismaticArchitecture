# Consolidation Benchmarks

This directory describes future tests of offline cross-experience developmental reasoning. It does not implement a consolidation engine or prescribe thresholds.

## Benchmark dimensions

- **Specific to general:** repeated similar experiences involving different people can support an appropriate transferable pattern.
- **General to specific:** evidence can narrow a broad Part when its generalization is too wide.
- **Relational formation:** repeated psychologically meaningful interaction with a referent can support a dedicated relational Part.
- **No unnecessary formation:** repeated mention without psychological significance does not require a new Part.
- **Merge:** genuinely functionally redundant Parts may consolidate while preserving lineage and history.
- **Split:** one Part with meaningfully incompatible roles or contexts may differentiate while preserving ancestry.
- **Provenance preservation:** structural changes retain historical origins without automatically making provenance an activation trigger.
- **Corrective replay:** prediction errors from waking experience remain available for offline reconsideration.
- **Memory reconsolidation:** revised meanings create new versions while preserving prior interpretations and Part perspective.
- **Therapy transfer:** corrective evidence in therapeutic interaction is assessed for appropriate later generalization, including the possibility of a relationship-specific exception.

Inspection should make the input cognitive period, selected replay experiences, perspectives involved, recurrence/co-activation, hypotheses considered, evidence accepted or rejected, mutations, provenance, retrieval-surface changes, and unresolved questions reviewable. Ambiguous evidence should preserve existing structure.
