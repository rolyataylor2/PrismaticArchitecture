# Identity Presets

This directory contains reusable starting identities for experiments. These describe initial self-models, not evolving identity state.

`question-library.json` contains every listed prompt from all five files in `examples/Example Identity Questions`, plus the Reactions scenario exercise. Questions are framed from the Identity owner’s I/my perspective and supply suggested context-search keywords. Each entry retains the original prompt in `sourceQuestion` for source completeness; each group retains its source answer guidance for provenance. `answer-guidance.txt` contains the researcher-provided general instructions, shown verbatim from the information button in both Trait dialogs. This catalog is researcher authoring material, independent of living Identity state. Selecting an example fills a draft question and keywords; only explicit trait creation persists it.

ADR 0101: Traits carry `self_definition` or `autobiographical` roles. Presets assign roles automatically in the picker and generated answers; the Trait editor can change them. Runtime excludes autobiographical Traits from all Self inputs and previews. Missing roles default to self_definition for compatibility. Background remains authoring data; no automatic Part access or formation is introduced.

Catalog attribution: 57 self-definition questions and 55 autobiographical questions. Cognition keeps broad traits, values and styles as self-definition while background and comprehensive mental-model synthesis are autobiographical. Life keeps preferences and philosophy as self-definition while person inventories, home, secrets and detailed desires are autobiographical. The Reactions exercise is autobiographical. Responsiveness keeps explicit preferences as self-definition while detailed stimulus-response patterns are autobiographical. Speech keeps broad voice attributes as self-definition while detailed reaction cues, formatting and portrayal instructions are autobiographical. Original source questions and guidance remain preserved.
