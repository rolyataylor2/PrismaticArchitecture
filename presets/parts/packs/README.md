# Part Packs

Part Packs are optional collections of starting Parts intended to bias an Agent toward a particular role or style of cognition.

Examples might eventually include:

- productivity;
- research;
- social companionship;
- creative exploration;
- game characters.

Part Packs are not part of the universal OntoAgentic psychology.

The base architecture should not assume productivity, task completion, helpfulness, curiosity, or caution as Agent-wide goals.

Such concerns should exist because the configured Identity and Part ecology contain them.

A Part Pack supplies starting cognitive ecology. It does not change the underlying architecture.
