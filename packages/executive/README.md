## Selected procedure handoffs (ADR 0143)

Native synchronous/background execution may enact a host-resolved current active method. The recorded contract captures its immutable version and exact procedure; adapters gain no library ownership or private cognitive access. `teaching-executor.ts` forwards recorded outcomes through a narrow host callback. The SDK performs independent retention validation and records feedback after persistence. One-time teaching, invocation and guidance bindings are not reusable method authority. No new inference task is introduced by exact procedure retention/use; adaptive planning remains required.

# Checkpoint monitoring boundary (ADR 0145)

Reached wait boundaries append host-checked completed counts and successful trace references. These are historical diagnostics, not resumable handles or evidence that the worker is still held. A deadline during unresolved review stops further submissions.

Boundary waits are tied to the review issued for the matching tool trace, rather than draining the Agent's inference queue. Failed review records infrastructure failure and blocks further submissions at that boundary. Terminal execution clears the host's review handle; cancellation can settle the worker while review remains pending.

ADR 0149 adds an opt-in cancellable boundary between successful native background calls. With checkpoint monitoring/review and `awaitCheckpointReview` enabled, the host waits for issued Agent inference before the next submission. Cancellation and the existing duration deadline independently release the worker; completed traces remain preserved. This permits selected pause without a worker/review deadlock, but does not yet modify or resume a remainder.

The host may observe persisted finished tool traces and enqueue lightweight ordinary disposition scoring. Native/background workers never await that inference and retain their original exact contract, grants, deadline and verification. Raw results stay in the audit ledger; checkpoint facts describe attributed tool statuses without declaring the goal complete. Advisory attention never authorizes a retry or intervention. ADR 0146 routes explicit selected pause through a separate host-control callback, bypassing MCP gateways and background job scheduling. The owning worker stops future submissions; an in-flight result remains unverified. Ordinary review and exclusive Self continuation are host cognition, not an automatic-action agent.

# External Executive infrastructure

When an exact native handoff has no selected executable steps, it emits one structured guidance request within the captured handoff budget, without constructing a gateway or submitting a tool. A zero budget blocks it. The request contains selected-goal attribution, operational difficulty, uncertainty and a request for explicit instruction; it never chooses a teacher or invents psychological meaning. The host persists and projects bounded factual feedback for later original-thread cognition. `needs_guidance` is paused and cannot submit through the tool gateway. Native/background `resume` enacts a fresh Self-selected supplemental contract after host consumption of the original request. The original segment becomes `continued`, preserving its action and provenance, and the successor supplies actual verification. Rejected responses return blocked synchronously even in background mode. Submitted-effect recovery remains pending; selected retention is described above.

Framework-scoped gateways also enforce duration from the recorded selected-contract event, independent of adapter cooperation. They reject expired submissions and supply deadline signals to MCP calls. The manager preserves timeout ambiguity as an unverified outcome; `budget_exhausted` distinguishes a host pre-submission budget rejection from tool failure.

`background-executor.ts` implements opt-in native background work through narrow host reporting callbacks. It returns a running handoff before starting the worker, enforces the per-Agent parallel-job admission budget, and supports cancellation and orderly shutdown. Native control signals stop future submissions; aborting an in-flight tool response remains unverified. The host retains contracts, current outcomes and immutable status/tool events. Worker startup is local to the handoff: constructing a new Application never recreates or replays saved running work. Evidence-based recovery/resume and cognition-mediated guidance remain pending.

Native execution uses sensitivity captured in each selected contract, with constructor settings retained only as a compatibility fallback for older contracts. The SDK retains exact procedures with evidence validation and mode-gated activation; the Executive gains no storage access or authority from a retained procedure. Researcher tabs administer profiles, MCP grants and procedure versions. Generalization and cognitive approval remain pending; selected exact-method teaching/use is described above.

## Selected procedural review (ADR 0153)

Researcher-only approval remains the default. The opt-in `self_selected` profile policy exposes bounded candidate review choices to Parts. An exclusive Self-selected approval/rejection operation resolves the exact immutable Agent Skills package, checks captured/current policy and current scope/version/evidence/grants, and atomically records the decision and new skill version. Approval dispatches no tools, changes no permissions or maturity, and requires a later fresh selected invocation. Storage independently checks selected review lineage and completion receipts. Inspection includes the review episode's expressed thoughts, bids and Self reason, alongside the preserved version history.

MCP progress notifications are bounded attributed diagnostics under the original call trace. At most 200 updates are retained per call, with 250 ms coalescing and a final buffered observation before the response. The tool-call inspector shows the latest server-reported count/total/message. Progress does not reset timeouts, validate success, count as a submitted step or create a settled correction checkpoint. Raw progress text remains outside Self inference.

Official SDK tool-list notifications invalidate the host catalog immediately. Subsequent discovery and calls share a fresh schema lookup before validating arguments; refresh failure never substitutes stale definitions. Notifications only invalidate metadata, without executing a tool or extending current grants and selected authority. Changes arriving during discovery remain pending for subsequent refresh.

ADR 0155 disables the Executive connection by default. Current per-Agent enablement gates every host tool submission even for an earlier contract. Already submitted results remain audit evidence; disabled feedback does not enter cognition.
