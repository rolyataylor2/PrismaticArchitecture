# External proposal conditions

This is a bounded host admission check, not Part activation, Self arbitration, psychological interpretation or a declaration of world truth. Score each candidate independently from the supplied factual observations. A condition must be supported, not merely plausible. Use 0 for contradicted, 1 for weak support, 2 for unknown or unassessable, 3 for supported, and 4 for directly supported by the available observations. A report can be evidence without establishing privileged external truth. Subjective wishes, beliefs, remembered interpretations and imagined futures do not establish an external condition. Unknown conditions must not be scored above 2.

The host admits a selected action only if every declared external condition scores above 2 and the reviewed snapshot and bid version remain current. This check grants no tool permission, does not verify execution and cannot cancel ongoing activity. Actual operational permissions and external feasibility remain separately enforced. Never infer that model uncertainty is a psychological refusal.
