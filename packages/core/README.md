## Embodied intention boundary

[ADR 0175](../../docs/architecture/decisions/0175-embodied-external-behavior.md) requires natural `act` for every external body behavior, including speech/questions and waiting. Runtime and generation schemas reject chat-only Say/Ask/Wait in embodied mode; internal inquiry and general chat Agents retain their existing boundaries.

[ADR 0174](../../docs/architecture/decisions/0174-embodied-intent-handoff.md) adds host-bound embodied WorldState and natural `act` proposals. Runtime rejects mechanical proposals and revisions in this action space. Selected contracts delegate bounded external realization without framework MCP tool authority; general `operate` contracts remain exact.

## Disposition interest thresholds

ADR 0173 derives thresholds from bounded long/short-term interests. Actual Self proposal selections reinforce once; activation and thought frequency do not. Elapsed WorldState time drives decay. Relevance-only scorer inputs exclude policy; recorded judgments retain thresholds separately.

## Continuous cognition (ADR 0165)

See [ADR 0165](../../docs/architecture/decisions/0165-continuous-asynchronous-cognition.md) and the [current audit](../../docs/development/CONTINUOUS_COGNITION_AUDIT.md). The runtime now admits overlapping observations, commits bounded independent scope jobs as they complete and serializes Self decisions. Per-Agent activation settings persist busy-scope rescoring, thought concurrency/queue bounds and per-observation activation-pass allowances. One-pass pause and explicit resume use the same runtime. Historical descriptions of a global batch barrier below no longer describe ordinary execution. Activation history is a researcher-only projection; it grants no cognitive authority.

Self answers (including requested subjective recall), focused revisions and generative prediction reflection now share the ordinary scope queue. Queued contexts coalesce within the same scope and inference purpose, so inquiry cannot discard prediction reflection; one running job per scope and shared resource bounds remain enforced. Admission deferral or changed owning versions preserve prior expressions without fabricated responses or stale psychological commits. Inquiry captures the scope's committed post-thought state while preserving its immutable experience snapshot.

ADR 0159 adds a researcher-only Store branching contract preserving owned psychology and history under remapped identities. This is administrative copying, not Part learning or a new cognitive subsystem. Dream framing and before/after snapshots never enter cognitive inputs.

## Self affect extension (ADR 0157)

`affect-domain.ts` defines natural-language Part proposals and separate selection, focus and feedback contracts. `affect.ts` projects a world-blind first-pass context, validates proposed/maintain/no-change/inquiry choices, bounds same-thread focus lifetime and calculates origin-cohort outcome counts without inferred learning or practical value. `affect-scoring.ts` independently judges proposals/controls and one bounded complementary addition. Separate provider capabilities support affect choice, restricted inquiry and owning-Part focused bid revision. Behavioral Self context can receive an explicit chosen focus separately from experienced affect. Ordinary cognition publishes attributed `part.affect_proposals` audit events; `self.ts` sequences baseline scoring, shared-budget inquiry, independent focused revisions and behavioral selection. `affect-history.ts` reconstructs carried focus and delayed outcome counts from completed `self.affect_cycle` records; failed attempts remain audit only. Read-only lifetime researcher analytics use the SDK projection and Affect Analysis panel. ADR 0157 and the Self affect thread audit track the full target.

## Conditional procedural consolidation (ADR 0147)

`agent-skill-package.ts` builds Agent Skills `SKILL.md` with standard frontmatter, readable applicability/procedure and relative exact-method/development references. Host-specific approval in an asset is historical metadata, not portable execution permission. Runtime package loading and import remain unfinished.

Conditional package construction requires exact same-Agent scope-compatible member versions and bundles their JSON assets with relative instruction links and criteria. Member definitions are included rather than requiring a foreign registry to resolve internal IDs.

`correction-boundary.ts` independently checks a reached boundary against live worker ownership, selected Agent/thread contract, exact settled prefix and actual submission count. It is an evidence gate, not correction selection/consumption or successor authority. Native wait boundaries apply it before and after review.

An ordinary checkpoint's opaque trace reference can resolve the latest reached boundary without exposing raw audit state. Conflicting/stale references and expired source deadlines reject. Returned remaining steps/duration retain the original absolute deadline; successor admission is still unfinished.

Conditional methods retain branch conditions/reasons and immutable exact member references. Public manifests reveal member criteria/constraints, status and current permission without raw arguments. Explicit branch invocation is required; no default branch or condition matcher exists. Preserved method verification checks parent and member versions independently.

## Selected external procedures (ADR 0143)

Ordinary operational proposals may explicitly include `teachProcedure` or a current active `skillInvocation`. Self selects the proposal; the host compiles immutable method/version authority, intersects stored/current budgets and enforces current grants. `skill-invocation.ts` resolves exact recorded procedures and validates preserved versions. `WorldState.externalSkills` exposes only bounded public descriptions, criteria, constraint declarations, limits and evidence limitations; it contains no raw tool arguments or source-Part state, never accumulates as facts and is excluded from factual evidence contexts used to evaluate predictions and Self. `maxSkillContexts` defaults to 20 (0–100). Retained procedures strip one-time guidance/teaching/invocation bindings. Generalization and semantic condition validity remain unproven.

## Soft activation associations (ADR 0139)

Disposition prerequisites no longer gate activation. Every live eligible scope receives a direct independent score; contributing/inhibiting keyword or disposition associations then inform one bounded second judgment using frozen direct scores and the identical WorldState. Final scores govern ordinary activation/admission. No recursive feedback, private-state sharing or automatic associative learning occurs. Legacy dependencies read as contributing associations; history stays preserved. See [ADR 0139](../../docs/architecture/decisions/0139-soft-disposition-activation-associations.md). This supersedes prerequisite descriptions below.

# Prediction-bound dispositions (ADR 0138)

Bounded cognition coverage examines the immutable experienced snapshot, active relevance definitions and expressed products after ordinary cognition. It may abstain or create testable gap hypotheses without an owning Part. Coverage has no Identity, private memory, bids or execution authority. Hypotheses propose versioned temporary prediction-bound dispositions for ordinary later-cycle activation, recall and Part generation. Gap outcome checks use factual-only later evidence; separate subjective reflection can retain a hypothesis-attributed episode without inventing a Part.

Online experience attaches evidence only. Offline INSTITUTIONALIZE requires repeated recorded appropriate ordinary use and creates a durable descendant with preserved prediction-bound disposition lineage. Correctness alone cannot promote relevance. Ended temporary scopes remain inactive; their histories and memories survive. Implementation verification and outstanding requirements are tracked in `docs/development/PREDICTION_SCAFFOLD_THREAD_AUDIT.md`.

After cognition and external handoff, experiential formation processes committed cycle memories, attaches evidence without semantic edits or creates a narrow provisional disposition. Offline learning now validates explicit structural operations against selected lived evidence and recorded activation/recall, preserving lineage and subjective episodes.
