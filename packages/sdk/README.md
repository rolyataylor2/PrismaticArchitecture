## Automatic candidate consolidation (ADR 0152)

The default consolidation policy is manual. Opt-in policies enqueue existing external procedural inference after a verified ended execution, either immediately or after a configured number of identical whole-procedure successes. Coordination waits for the selecting cognitive cycle; tools and cancellation remain independent. Current/captured disabled learning, unverified/failed outcomes, missing evidence and previously consumed triggers produce no automatic inference. Reports retain trigger execution and policy. Candidates remain proposed even under validated-automatic teaching mode; this policy grants no approval, maturity or tool authority and does not replay work at startup.
If automatic policy changes while inference is pending, the result is retained as a failed learning report without candidates. The verified execution is unaffected and the trigger remains consumed. A new explicit manual request can reconsider evidence; toggling policy does not automatically replay failed inference.
Automatic assessment/scheduling exceptions before inference produce failed trigger reports with the recorded execution ID. Empty report input does not imply absent source history; no policy or model output is fabricated. Retained triggers cannot retry automatically, while a later explicit manual request remains available. Persistence outages cannot undo already recorded tool outcomes.
