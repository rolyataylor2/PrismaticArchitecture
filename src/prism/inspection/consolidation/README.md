# Consolidation Inspection

Researchers should eventually be able to inspect the input cognitive period; selected replay experiences; Parts/perspectives involved; repeated co-activation and referents; prediction outcomes (including confirmation, contradiction, ambiguity, and causal attribution); activation spikes; waking episodic memories and their prediction/experience ancestry; candidate relational Parts and generalizations; proposed specializations and memory reconsolidations; association/charge changes; split/merge proposals; accepted and rejected mutations with reasons; provenance preservation; and retrieval-surface changes.

Inspection should answer: Why was the Paul Part created? Which information moved into it? What remained generalized? Which triggers changed? Which evidence supported the change or was rejected? What remained unresolved? Did consolidation create the change or preserve a waking mutation? Did this create new accidental activations?

Association graph views are conceptual and need not use a graph database. Distinguish active triggers, associations, provenance, lineage, memory references, and stickiness.
