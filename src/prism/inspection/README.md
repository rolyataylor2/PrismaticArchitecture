# Inspection

Inspection makes internal behavior observable, including active Parts, activation, motivations, bids, outcomes, inference requests, model selections, state transitions, memories, identity changes, and historical comparisons. It observes cognitive processes without owning them.

Future inspection should expose consolidation inputs, repeated referents, candidate formation/split/merge operations, proposed information moves, retrieval-surface changes, preserved provenance, rejected proposals and reasons, and committed mutations. Association views should distinguish active trigger edges, associations, provenance, lineage, and memory references; graph storage is not implied.

One future cognitive execution trace should distinguish frozen WorldState, vector candidates, per-Part activation Scores, derived rank, activation-policy result, activated Parts, first-pass Part bids and forecasts, bounded Self arbitration, optional world-blind deliberation, final choice, prediction scheduling, and model execution telemetry. Operational inspection must not automatically become Agent memory or Self context.
