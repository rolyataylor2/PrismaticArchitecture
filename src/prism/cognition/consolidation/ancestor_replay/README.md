# Ancestor Experience Replay

Ancestor replay is an exceptional, controlled developmental operation that retrieves an interpretation-light experience through a subjective memory's opaque ancestry and re-exposes it to the current owning Part.

The current Part interprets the experience using its present development. The purpose is possible reinterpretation, not asking the event archive to correct memory. Objective history supplies evidence and does not determine psychological meaning. A Part may preserve, soften, intensify, nuance, or reject a proposed reinterpretation.

This is distinct from ordinary consolidation replay, which primarily reconsiders digested Part memories, predictions, outcomes, associations, conflicts, and other psychological traces. Ancestor replay must remain rare, selective, and explicitly traceable; it is not a default sleep step, fixed schedule, automatic consequence of retrieval, or general-purpose objective-memory API. Selection criteria remain experimental.

Inspection should eventually expose the ancestor event ID, subjective memory and version, owning Part, replay reason, interpretation before and after replay, proposed mutation and whether it was accepted, and preserved provenance/version lineage.

This is documentation scaffolding only; no replay mechanism is implemented here.
