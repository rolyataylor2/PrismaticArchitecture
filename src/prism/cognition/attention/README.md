# Cognitive Attention

> Experimental, non-canonical. Attention is not a mandatory post-bid filter between Parts and Self; scalability filtering primarily occurs through Activator candidate retrieval.

This subsystem concerns which information becomes available for deeper cognition and Self integration. Potential sources include Parts, perception, memories, predictions, internal conflict, and Identity concerns.

Attention remains separate from Part activation. An activated Part is not necessarily consciously available to Self. The implementation should eventually permit limited cognitive bandwidth rather than loading every available internal state into every inference.
