# Prediction Lifecycle

A Part carries at most one unresolved prediction. New experience normally continues, revises, resolves, abandons, expires, or invalidates that prediction rather than stacking another. Revision preserves prior versions.

Conceptually: no open prediction → formation → open → continuation/revision/early resolution/abandonment/expiry/context invalidation → evaluation and possible memory/development → no open prediction.

A horizon describes when an expectation should become knowable; it is distinct from action execution duration. Evaluation may occur early when decisive evidence appears. Expiry without evidence need not mean right or wrong. No fixed horizon, status enum, threshold, or timing policy is established. This is cognitive learning, not a generic task scheduler.
