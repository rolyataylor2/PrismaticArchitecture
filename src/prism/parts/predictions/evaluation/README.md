# Prediction Evaluation

Evaluation conceptually receives:

```text
PREDICTION-TIME CAPSULE
        +
LATER WORLDSTATE EVIDENCE
        +
EXECUTION / INTERRUPTION FACTS
```

The capsule preserves what the owning Part expected and the Part-selected event context, interpretation, activation/spike context, confidence or uncertainty, and horizon. Later factual evidence may arrive before the nominal horizon; decisive evidence can permit early evaluation. If circumstances make the question unanswerable, the Part may treat it as abandoned, expired, or context-invalidated rather than wrong.

The owning Part may interpret confirmation, partial confirmation, contradiction, ambiguity, causal attribution, a revised interpretation, and whether an episode deserves memory. Evaluation is not binary and is not assigned by the runtime. Preserve actual execution and interference separately from Self's selection and the external outcome. No global reward score is required.
