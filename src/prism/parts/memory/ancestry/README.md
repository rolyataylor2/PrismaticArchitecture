# Subjective Memory Ancestry

A subjective Part memory may retain stable references to one or more ancestor experiences from which it developed. These references support provenance, inspection, controlled replay, and research.

An ancestry reference is opaque in ordinary use. It means that the memory descended from an experience; it is not an automatic recall link. Ordinary memory retrieval returns the current subjective memory directly and does not dereference objective experience records. A Part can know its memory's ancestry without reading the ancestor event.

Different Parts may hold different memories descended from the same experience. Ancestry can verify this shared origin without deciding which interpretation is emotionally or psychologically correct. Objective event access belongs to inspection, experiment harnesses, ancestry verification, and explicitly controlled consolidation replay, not ordinary Part cognition or Self.

This is documentation scaffolding; no ancestry mechanism is implemented here.
