# Part Memory

This subsystem concerns subjective memory belonging to individual Parts. Part memory is distinct from authoritative simulation history and external records.

A Part's memories support its beliefs, activation, predictions, strategies, and bids. Different Parts may form different representations of the same experience. Prediction-time context capsules are a major encoding source: evaluation may connect the preserved experience with later outcome and the owning Part's current interpretation to form an episode during waking cognition. The memory is not a copy of the capsule or WorldState. Salient unpredicted events may also form memories; prediction is not required.

Parts do not directly read one another's private memories; Self may mediate requests for remembered information during an integrative episode. A Self reconstruction is not canonical autobiographical memory. Current subjective memory content remains directly retrievable without LLM reconstruction. Prior versions remain immutable; ancestry may link a memory to a prediction and experience without making objective history ordinarily accessible.

## Mutation and provenance

Important reinterpretation is incremental and versioned. Preserve opaque ancestry, originating experience, later evidence, and developmental links where useful. Objective ancestor replay remains exceptional and controlled; it is not ordinary retrieval.

## Consolidation boundary

Sleep primarily consolidates already formed subjective episodes and selected psychological traces into broader learning. It does not need to create every episode from scratch, and generalization does not erase the episodes. Machine metadata may support ownership, provenance, retrieval cues, entity/time references, version identity, related memories, and history links; the exact format remains open.

## Subjective assertion

Memory content may preserve a Part's perspective as reality (for example, “He abandoned me.”). Metadata can establish subjective ownership without changing the remembered words into detached report.

## Current cognition boundary (ADR 0098)

Part cognition returns only interpretation, thought, evidenceSummary and an optional proposal. It produces no cues, memory or mutation. Additional Parts are considered on later cycles through attributed, decaying expressed thoughts in immutable WorldState; vector filtering and independent activation scoring both consider retained thoughts. Ordinary waking memory formation and mutation occur only through prediction outcome reflection. Offline development and explicit researcher edits remain separate existing paths. Older same-cycle cue and direct cognition-encoding guidance is superseded.
