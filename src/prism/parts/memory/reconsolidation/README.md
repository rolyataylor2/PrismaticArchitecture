# Memory Reconsolidation

This directory marks conceptual scaffolding for incremental reconsolidation of subjective Part memories. A memory may be reconsidered when it becomes relevant alongside new evidence or context. This is **subjective reconsolidation** and may occur during ordinary cognition or consolidation without reopening any objective event.

**Objective ancestor replay** is a separate, exceptional process: a controlled developmental operation may retrieve an opaque ancestor experience and re-expose it to the current owning Part. It is one possible source of evidence for reconsolidation, not a requirement. Ancestor replay must not become a general-purpose objective-memory API or a routine sleep step.

An accepted change creates a new memory/Part version; previous versions remain immutable. Preserve the Part's relational perspective and distinguish current subjective meaning from objective history. The current developed Part interprets any re-exposed experience. Objective evidence may inform interpretation but does not automatically replace it or determine psychological meaning. Significant reinterpretation should be capable of preserving the relationship to the earlier view when meaningful.

No reconsolidation mechanism is implemented here.
