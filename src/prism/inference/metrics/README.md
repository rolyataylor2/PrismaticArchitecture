# Inference Metrics

Inference efficiency should be measurable.

Potential metrics include calls per cognitive cycle, total stored Parts, vector candidate count, candidate-retention ratio, Jev activation request count, Parts scored per Jev request, each candidate's activation Score, activated Part count, candidate-set stability measures, WorldState token size, input tokens, reusable/cached input tokens, uncached input tokens, output tokens, latency, model/provider, cost where known, cache hit/miss information, and Part inference concurrency.

Metrics are operational information. They must not become psychological inputs to Parts or Self unless a future explicit architecture decision introduces such a concept.
