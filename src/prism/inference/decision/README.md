# Decision Inference

Decision inference provides bounded semantic judgment. Part activation uses independent graded Score-style judgments; Self arbitration uses Choice over existing proposals or `DELIBERATE`.

Its callers define the possible result space before inference occurs.

Current cognitive users are:

- Activator;
- Self arbitration.

Decision inference should return structured results suitable for code.

The domain layer should not depend upon one vendor.

The initial adapter is Jev.
