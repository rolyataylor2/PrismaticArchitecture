# Memory Services

OntoAgentic does not assume the complete Agent possesses one canonical autobiographical memory store.

Subjective autobiographical memories primarily belong to Parts.

Objective experience/audit history is not this subsystem's hidden autobiographical memory. Current subjective Part memories are directly retrievable; opaque ancestry may support provenance without automatic event dereferencing. Objective records are not supplied to Self or ordinary Part retrieval and may be reopened only through rare controlled developmental replay.

This subsystem exists for shared memory-related services and interfaces that do not logically belong to one Part. Possible future responsibilities include coordinating memory queries, indexing retrievable Part-held memories, interfacing with external records, supporting Identity's reconstruction of past events, and common memory provenance concepts. It must not silently become an authoritative internal transcript of the Agent's life.

## Subjective versus external record

Part memory answers: “What does this perspective remember?” External records answer: “What evidence exists about what occurred?” Self may receive both only through defined mediation while consulting Identity. Neither automatically overwrites the other.

## Ownership

The exact technical implementation is open. Cognitive ownership of subjective autobiographical memory remains with Parts.
