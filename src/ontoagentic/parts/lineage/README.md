# Part Lineage

Records developmental ancestry when Parts split, merge, specialize, or produce successors. History records chronological change; lineage records descent. Preserve provenance.

Motivational provenance may also be recorded when one Part's mission contributes to formation of another, such as a college-completion perspective contributing to an assignment-completion perspective. This does not establish a runtime parent/child command hierarchy.

Lifecycle operations have lineage implications:

- a split creates multiple descendants of the original Part;
- a merge creates a descendant with multiple source ancestries;
- specialization or succession preserves the developmental source;
- archival and reactivation preserve the same Part's history rather than creating an unconnected replacement.

The original Part and all source Parts remain historically recoverable. Lineage records developmental ancestry; it does not create a recursive hierarchy of autonomous agents.
