# Cognition

This directory coordinates cognitive processes involving Parts, including future cognitive cycles, interpretation, proposals, deliberation, conflict handling, outcomes, prediction evaluation, episodic encoding, and integration of experience. Cognition must not be reduced to one completion.

An activated Part may contribute an interpretation, thought, question, context, prediction, and/or action proposal as psychologically appropriate. Prediction may follow a significant activation change and precede an information-gathering proposal. A proposal may test a current prediction; it does not require a new prediction, and each Part normally has at most one unresolved prediction. The canonical shared-WorldState and world-blind Self boundaries remain in force.

## Current cognition boundary (ADR 0098)

Part cognition returns only interpretation, thought, evidenceSummary and an optional proposal. It produces no cues, memory or mutation. Additional Parts are considered on later cycles through attributed, decaying expressed thoughts in immutable WorldState; vector filtering and independent activation scoring both consider retained thoughts. Ordinary waking memory formation and mutation occur only through prediction outcome reflection. Offline development and explicit researcher edits remain separate existing paths. Older same-cycle cue and direct cognition-encoding guidance is superseded.
