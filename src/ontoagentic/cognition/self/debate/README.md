# Self-Mediated Deliberation

This historical directory now documents DELIBERATE, which supersedes DEBATE under ADR 0105. Deliberation includes inquiry, prediction clarification, proposal requests and comparing disagreement; it does not require opposing Parts.

After bounded Choice selects DELIBERATE, one world-blind generative call emits why_deliberate, primary_c, secondary_c, missing_information, target_parts, question in that order. The eight C qualities guide stance and inquiry rather than becoming actions or Parts. Secondary quality is optional and different from primary. The rationale is concise, not hidden chain-of-thought. Self generates one minimum useful neutral question without advocating an outcome or inventing an intention.

A selected Part deliberate bid uses its own targets and question through the same routing machinery without Self recreating its intention. Only available contributors may be targeted. Parts receive the same immutable WorldState, their own private context, their current bid and explicitly mediated inquiry responses. In one generation they answer first, then retain, replace or withdraw their current bid. Nonparticipants remain unchanged. Replacement creates a later discrete bid referencing the previous record; no bid version layer or separate update pass exists.

Every inquiry returns to the exact same bounded arbitration with Identity, current bids and attributed responses. Self remains world-blind. Configurable round exhaustion grants no invented action or automatic winner. Internal inquiry never reaches external execution.
