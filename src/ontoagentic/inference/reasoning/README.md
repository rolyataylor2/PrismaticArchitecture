# Generative Reasoning Inference

This subsystem provides open-ended model reasoning required by OntoAgentic cognition.

Primary users include Parts, Self deliberation, Part adaptation, and memory reinterpretation.

Generative reasoning may eventually route to OpenAI, Anthropic, Gemini, xAI, local models, or other providers. Different Parts may use different reasoning resources. The reasoning model performing inference does not define the identity of the Part using it.
