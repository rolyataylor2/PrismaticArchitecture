# WorldState, prospective experience and affect navigation

Source: [shared discussion](https://chatgpt.com/share/6ac32932-dc9c-83e8-ac57-5cfd66a3c862), preserved in `WORLDSTATE_THREAD_SOURCE.md`.

Status: complete. All thirteen requirements have implementation and verification evidence below. This request extends ADR 0133 rather than reverting to its superseded online stages.

## Requirements and acceptance evidence

Researcher clarification during implementation: evidence supporting formation is lived experience, memory and previous observations, not an enforced objective worldview. The predicted future must remain the Part's subjective expectation. Outcome comparison must preserve the owning perspective and distinguish later experience from imagined confirmation, without privileged simulation truth access or automatic neutralization.

1. Assemble an experienced WorldState with distinct external observations, attributed remembered interpretations, current natural-language affect/stance and prospective predictions. Preserve immutable shared cycle snapshots and source/thread attribution. Evidence required: runtime assembly and immutable-context tests.
2. Construct a prospective layer from open predictions, retaining owning Part, prediction/version IDs, uncertainty, horizon, context, conditions and conflicting alternatives. Never promote it to external truth. Evidence required: conflicting prediction and provenance tests plus inspection.
3. Keep trajectory predictions separate from action-conditioned futures. Mutually exclusive proposed actions must not become one baseline future. Evidence required: branch projection tests and bid context inspection.
4. Supply prospective experience to current cognition and disposition activation. Final discussion explicitly permits anticipatory activation, superseding the intermediate prohibition. Avoid unbounded same-cycle recursive prediction cascades. Evidence required: ordinary pipeline anticipatory activation, bounded sequencing and thread-isolation tests.
5. Preserve individual prediction evaluation and owning-Part learning against later factual evidence. Imagined futures and subjective affect must never count as observed confirmation. Evidence required: separate factual evaluation context and lifecycle tests.
6. Represent affect as rich natural language expressing appraisal, salient memories, expectations, stance and action tendencies. Numeric emotion vectors, compulsory labels and affect-congruence multiplication are superseded suggestions. Evidence required: domain schemas, prompts and runtime contexts.
7. Parts propose interpreted subjective worlds alongside behavior. Self receives mediated interpretations, affect and futures while remaining world-blind and Identity-guided. Evidence required: exact Self input tests excluding raw external/private state.
8. Self choice can choose an emotional/interpretive posture that influences later attention, recall and cognition. Preserve dissent instead of deleting incongruent Parts or making affect authoritative. Evidence required: selection/carryover tests and contrasting perspectives.
9. Preserve chronological pre-choice, chosen interpretation and resulting experienced states. Self may navigate back to an earlier mediated stance and reconsider with subsequently learned evidence; this is perspective traversal, not rollback of external facts, memories or developmental history. Evidence required: persisted navigation, restart, later-evidence and world-blind access tests.
10. Keep this one cognitive mechanism: no emotion engine, global planner or second sovereign decision-maker. Models author psychological meaning; code validates, attributes, persists and sequences it. External execution and offline consolidation remain separate.
11. Review affected factory prompts, task descriptions, provider routing and Settings → Prompts together. Update architecture before runtime changes and preserve old ADR history. Evidence required: task catalog/schema/provider tests.
12. Preserve imagined future as the Parts’ assumed unfolding/inevitable subjective reality. Prompt language controls its influence; no forced objective future or runtime numeric weight. Self must not receive synthesized prospective state or an independent forecast collection, only active Parts’ expressed predictions and justification. Self may make bad external choices; deliberation can request missing interpretations through ordinary cognition. Evidence required: exact Self context tests, affected prompts and bounded perspective recruitment tests.
13. Add runnable Simulation Tests for prospective anticipation, contradiction/calibration, affect-dependent interpretation and return-to-stance navigation, including controls, normal pipeline use, provider provenance, preserved evidence and explicit limitations. Fixture plumbing does not prove psychological hypotheses.
