## Requirement evidence

| Conclusion | Implemented contract and evidence |
| --- | --- |
| Consequential coverage gaps generate hypotheses instead of directly creating durable dispositions | `core/src/cognition-coverage.ts`, `runtime.ts` and the coverage factory prompt implement SUFFICIENT/INVESTIGATE, consequential value and bounded alternatives. `experiential-formation.ts` permits attachment only. Scaffold tests reject direct online durable creation. |
| A hypothesis need not have an existing Part | `domain.ts`, `predictions.ts` and SQLite accept explicitly attributed gap-origin predictions and linked subjective episodes with null Part ownership. Ordinary Part predictions retain the one-open constraint. Tests cover both origins and cross-thread isolation. |
| Predictions include adjustable unresolved states, hidden causes and continuity | `state_hypothesis` is supported across domain, prompts, providers and inspection. Coverage can revise, abandon, expire or invalidate supplied open gap hypotheses, even at full capacity. Tests preserve old versions and distinguish expiry from falsity. |
| Temporary relevance is the same disposition type; zero or multiple scopes may support a hypothesis | Prediction drafts accept scaffold arrays with discriminating evidence, retrieval intent, memory hints, tracked distinctions and future value. `predictions.ts` creates versioned temporary Dispositions and retains source hypothesis/version attribution. Ordinary Part and gap tests exercise this shared pathway. |
| Investigation uses ordinary independent cognition | `constructed.ts` retrieves eligible prior-cycle scopes through activation, private recall and independent Part generation. Immutable snapshots, previous-cycle prerequisites, next-cycle attention and world-blind Self remain enforced. Access-boundary and lifecycle regressions verify these contracts. |
| Investigation is bounded without making activation compete or creating a planner | Runtime limits new/open gap hypotheses and admitted temporary Parts. All candidates retain independent scores; admission records deferred scopes. The budget regression scores three scopes independently and admits one. No global task manager or investigator is introduced. |
| Later evidence can produce subjective episodes and further explanations | Separate bounded hypothesis checks and generative reflection use later factual evidence and the owning hypothesis capsule. Gap episodes retain subjective meaning, provenance and linked prediction. Coverage receives expressed products and evaluated hypotheses for further explanations; it cannot inspect private Parts or supply bids to Self. Tests cover outcomes, memory ownership and preserved histories. |
| Correctness and reusable relevance are separate | Closure ends associated temporary scopes without durable promotion. Offline INSTITUTIONALIZE requires ended investigations and repeated recorded useful participation/recall/experience. The lifecycle test rejects premature promotion and verifies explicit later institutionalization. |
| Consolidation preserves development and can refine, generalize, split, merge or archive | Existing reconciliation operations remain; institutionalized descendants retain lineage while source records survive. Offline inputs include selected disposition histories, actual traces, episodes and all versions of selected hypotheses. Ended scopes cannot be silently revived. Disk reopen tests verify source, descendant, prediction and episode persistence. |
| Persistent causes emerge through future cognitive value rather than a predefined person mechanism | Hypotheses express prediction, retrieval, causal, action and compression value plus why existing structures are insufficient. Factory prompts introduce no person ontology, compulsory introduction memory or seeded resolver. Recurring-interlocutor and nonhuman-device experiments use explicit ordinary experiences and controls. |
| Provider, prompt and inspection contracts stay synchronized | Coverage, hypothesis outcome and reflection tasks have schemas, routes, factory prompts, catalog entries and previews. Jev remains behind its adapter; mocks explicitly abstain or leave outcomes unresolved. UI exposes gap origin, current-state hypotheses, scaffold evidence/history and nullable formation origins. Provider/access and actual Chrome tests verify these surfaces. |
| Runnable experiments exercise the normal pipeline and report honest evidence | `sdk/src/prediction-scaffold-simulations.ts` registers five sourced Simulation Tests: blank bootstrap, conflicting coverage, failed explanation, recurring interlocutor and device continuity. Fresh Agents receive ordinary messages/sleep; controls, provenance, limits and evidence are retained. Observers count actual participation, reject same-cycle scaffold use and avoid vacuous closure claims. Simulation regressions verify reporting. |
| Architecture and tests accompany the change | ADR 0138, canonical flow, invariants, overview, subsystem READMEs, root README/AGENTS and task descriptions reflect the revision. Six scaffold regressions cover runtime, access, adjustment, ordinary Part predictions, admission and persistence; existing development/provider/browser expectations reflect the new contracts. |
