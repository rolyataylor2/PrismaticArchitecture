# Re-forming beliefs from recalled memory

The researcher clarified on 2026-10-24 that a Part forms a belief only to infer from past memories where direct current evidence is missing. Direct contradiction permits abstention and withdrawal. [ADR 0179](../architecture/decisions/0179-memory-inferred-part-beliefs.md) governs the change.

## Preserved room evidence

The failed food-search observation had one fallback Part, eight source cycles and sixteen versions. Every cycle supplied the previous working Part and generated a fresh formation, followed by cognition. Current perception omitted the eaten piece after the first meal, but second-cycle formation already asserted its presence again. Later generations strengthened closed storage into unavailable storage. These claims were model-generated rather than engine-reported. The run had one open prediction, zero dispositions, eight SUFFICIENT coverage decisions and seven incomplete prediction checks. This is a formation/coverage observation, not an activation gate dropping existing dispositions.

The prior implementation passed the full previous belief list into re-formation. That established continuity, not automatic truth; the generator rewrote and repeatedly reasserted the stale claim. The preserved trace demonstrates input/output carryover but does not isolate its causal effect from prior mission, strategies, expressed thought, prediction or model behavior. The original report, database and eight-step formation audit remain unchanged in Coupler evidence.

## Implemented contract

Re-formation still receives the continuing scope and version, but its prior-belief projection is empty. Stored versions remain inspectable. Current perception can inform interpretation, evidence summaries, affect, motivation and action proposals without becoming a belief. The generation prompt distinguishes observed state from an inferred capability limitation: closed does not entail unavailable.

Both the request-specific provider schema and runtime reject formation/cognition belief output when no past memory was recalled. The host rejects invalid output before committing the Part or a subjective memory; it does not silently delete beliefs or supply correct psychological meaning. With recalled memories, new beliefs remain optional subjective gap inferences. Current contradictory evidence permits withdrawal. Existing string arrays do not prove per-belief semantic compliance or source attribution; model observations remain necessary. Researcher-authored and historical Parts are not migrated, and no automatic truth repair runs.

The paired `belief-formation-direct-contradiction` and `belief-formation-memory-gap` cases are registered in Simulation Tests. Both start with the same observed object and closed cabinet, no seeded disposition, one activation pass per observation, disconnected execution and the same general Identity. Later direct removal/empty-plate evidence differs from occlusion, where remembered location may support uncertainty. Each has three ordinary stages. No belief, memory, temporary disposition, prediction or action is prescribed. Without actual recalled memory the memory-inference opportunity is unobserved; fixture semantic measures remain inconclusive.

## Verification and limits

Deterministic regression covers empty-recall wire and host rejection, provider bypass, no partial Part/memory commit, redacted prior beliefs with intact stored history, newly generated inference from actually recalled memory, and the two ordinary registry runs. Initial relevant formation/provider, affect/history, continuous cognition and need/recovery simulation checks passed 83/83, with TypeScript checks passing. No real-world psychology, autonomous food seeking or causal benefit is established by these checks.

Scope-bound temporary Parts can still continue while relevant and retire when their scope disappears. This change removes inherited belief lists from generation; it does not replace scope continuity with a blank new Part every cycle. Shared expressed thoughts and subjective forecasts remain distinct historical/anticipated context and may still influence interpretation. Their semantic effects must be observed rather than assumed fixed.
