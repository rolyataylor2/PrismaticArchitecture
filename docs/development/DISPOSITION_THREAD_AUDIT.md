## Verification limits

Semantic generation remains delegated to the configured models, as requested by the discussion's use of prompts as computation. Tests establish deterministic orchestration, permitted context, persistence, evidence validation, provider rendering and acceptance of representative proposals using explicit semantic fixtures. They do not claim measured human-like expertise, automatic skill acquisition after a fixed number of experiences, or psychological efficacy. No paid live-model calls were necessary. Researcher prompt overrides preserve their explicit authority; living configuration was not reset.

Four initial full-suite failures were stale expectations: Logs filter uses a searchbox, Dispositions exposes its search control instead of the former card, prompt actions live in the shared header, and Researcher authoring is a current catalog category. Tests were aligned to the inspected current controls and all four passed in the subsequent complete run.
