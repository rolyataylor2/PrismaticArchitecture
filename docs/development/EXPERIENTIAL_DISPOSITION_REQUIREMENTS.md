## Current evidence

1. **Relevance, not belief or stored Part.** Domain disposition fields and `experiential-formation.ts` express cue-conditioned retrieval intent. Formation/cognition, activation and reconciliation factory prompts preserve this distinction. `constructed.ts` retains independent code-owned temporary scoped Part assembly; runtime Self remains mediated/world-blind.
2. **Conservative online creation after experience.** `formFromExperience` processes committed cycle episodes after ordinary cognition/external handoff. Strict online outputs allow only abstention, evidence attachment or provisional creation. Cue-specific experiential citations persist and validate at storage. The ordinary-pipeline development regression proves creation does not activate its own cycle, and evidence attachment preserves scope/cues.
3. **Experience without mandatory forecast.** Ordered Part reflections produce ordinary subjective memories independently of resolved forecasts. The nonprediction formation regression and experiential-provisional registry scenario cover this route. Pretrained knowledge is interpretive input, not claimed biography; prompts prohibit fabricated experiential support.
4. **Immediate outcome memory and pending reconciliation.** `Predictions.apply` creates outcome episodes atomically, links them to originating disposition scopes and historical versions, and leaves relevance interpretation pending. Failed-outcome regression checks linked provenance, unchanged old contents/versions and unknown retrieval usefulness. No numeric global punishment or forced split follows bounded failure.
5. **Fast behavior through contrary recall before sleep.** Memories remain in ordinary subjective retrieval and code-owned chronological assembly. Existing accessibility/constructed tests cover shared biased episodes and contradictory interpretations. Forest/desert registry includes a waking retest before sleep; interpretation quality is explicitly empirical, not scripted success.
6. **Contrastive reconciliation and abstention.** Strict offline operations cite source dispositions, selected episodes, retrieval judgments, contextual distinctions and alternative explanations. Runtime validates repeated independent cycles; multiple episodes from one event cannot fabricate recurrence. Development regression distinguishes appropriate recall plus failed outcome from evidence supporting specialization/split/archive.
7. **Operation-specific conservatism.** Code-owned policy distinguishes specialization, cross-context generalization, per-cluster split, repeated overlapping-coactivation merge and evidence-supported archive. Dependencies reference existing structures. Semantic relevance judgments remain model-authored, not predefined biome/personality categories. Policy values are experimental; textual context differences alone do not prove psychological generalization.
8. **Versioned structure and continuity.** Transactional reconciliation appends versions/lineage, preserves split parents and merge sources, archives without deleting ancestry and keeps memories unchanged. History regression covers split, merge, archive, dependency edits, researcher restoration/deletion and preserved source versions. SQLite persistence/restart regression covers metadata and rejected forged references.
9. **Prospective provisional development.** ASSESS_HYPOTHESIS requires repeated later-cycle evidence; appropriate recall can establish linguistic confidence/status without scope edits. History regression rejects formation evidence as prospective support and accepts later attributed episodes. Structural refinement/archive can qualify or retire refuted descendants while preserved parents remain available; no automatic outcome-based promotion occurs.
10. **Separate memory reinterpretation.** Independent task receives selected subjective evidence only, requires support and continuity, rejects stale/unselected revisions and appends versions. Dedicated regression proves unsupported rejection, earlier meaning preservation and unchanged dispositions. Structural reconciliation itself never writes memory content.
11. **Code-owned provenance and statistics.** Storage validates same-Agent historical versions, memory formation cycle/thread, cue citations and memory-linked prediction references. Researcher-only statistics derive unique activation cycles and bounded outcome counts from recorded events; model outputs cannot invent them or turn them into activation weights. Development tests assert formation-cycle count zero and real subsequent failed-outcome counts.
12. **Prompt/provider/UI integration.** Formation, reconciliation, prospective assessment and memory reinterpretation have strict provider schemas, catalog entries and editable factories; actual OpenAI/Ollama transport tests cover every constructed task. Previews project recorded permitted input. Chrome inspector regression checks developmental confidence, intent and reconciliation sections; raw references/cue provenance and statistics are inspectable. User-authored overrides retain authority without changing runtime validation.
13. **Runnable sourced experiments and preserved observations.** Shared Simulation Tests registry includes salient nonprediction learning, stochastic outcome mismatch, forest/desert/partial-mountain/return transfer, prospective wetland counterexamples and semantic/descriptive bootstrapping. Existing registry adds disagreement, generalization and negative controls. All use ordinary messages/sleep on isolated Agents, with sourced hypotheses, explicit starting conditions, controls, criteria, limitations, provider/prompt snapshots and stored reports. Workflow tests run every scenario and preserve honest fixture/inconclusive results. They do not prescribe model conclusions or claim human-psychology validity.
