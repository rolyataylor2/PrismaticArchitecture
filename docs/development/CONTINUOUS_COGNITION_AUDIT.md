## Recent integration corrections

Queued Self answers previously superseded queued prediction reflections because coalescing used only the scope. Coalescing now also uses inference purpose while preserving shared resource limits and one running scope job. A fallback instance receives the same busy-retirement protection as disposition-bound instances. The unselected prediction test now resolves and retains its subjective episode.

Prediction and pending-owner reviews no longer hold up a ready Self decision. Learning and review promises are observed immediately and drained separately. A Self inquiry remains an explicit recruitment request even if the target answer was deferred; no response is fabricated. Recruitment tests wait for asynchronous attention before shutdown and inspect failures on their actual source cycles.

Prediction outcome/reflection worlds contain only factual evidence after the committed frontier. Legacy retained runtime tests preserve their historical contract; a separate production test proves the new boundary.

Desktop/mobile inspection found and corrected ResizeObserver writes, an oversized model-settings header, broken chronology timestamps and an oversized Activation header. Dense chronology and exact evidence tables scroll horizontally; missing activation remains a gap. Live affect choices remain separate from completed historical cohorts.
