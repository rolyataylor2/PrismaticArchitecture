- Sleep queries selected event types rather than rereading raw audit history. Each owner receives only its own memories/predictions plus public population retrieval descriptions. Invalid memory-owner mutations are rejected without changing state.
- Explicit recovery marks an interrupted record failed with researcher origin; it does not replay actions or erase committed development. Confirm the old process stopped before invoking recovery.
