# Experimental Cognitive Settings

This catalogs candidate dimensions for comparison, not a permanent configuration schema. Experiments may vary Part trigger and activation behavior, Part cognitive capability, mission rigidity, strategy flexibility, memory influence, forecasting horizon, uncertainty, time-to-impact, prediction learning, Part development, and Self inquiry or mediation depth.

The canonical boundaries remain fixed: WorldState is objective; Parts interpret and forecast; Self selects using Identity; automatic behavior is fast Self selection; attention is not a mandatory post-bid stage; simulation is optional. No numeric defaults are defined.
