# Memory Reconsolidation

A Part's subjective memory is a developing interpretation, not an immutable transcript and not an objective audit record. When a memory becomes relevant again and new evidence or context is available, its owning Part may reconsider what the experience means.

```text
existing subjective Part memory
→ memory becomes active or relevant
→ new evidence or context is available
→ owning Part compares its prior interpretation with current evidence
→ possible incremental semantic revision
→ a new memory version, with prior versions preserved
```

For example, an interpretation may develop from “Paul was trying to control me,” to “Paul was invasive and I assumed he was trying to control me,” to “Paul asks intrusive questions. I still don't know whether he was trying to control me.” This is development of relational reality, not sudden discovery of objective truth.

Revision is neither automatic nor guaranteed. A Part may discount an exception, attribute kindness to obligation, or remain distrustful. Motivated resistance preserves psychological continuity and can itself be inspected as meaningful development.

Consolidation replay may consider objective evidence alongside the memory, but objective history does not silently correct or overwrite subjective meaning. The memory's owner interprets evidence from its own perspective. Accepted semantic changes create new versions; historical versions remain immutable and provenance is preserved.

This scaffold defines no revision threshold or numeric formula. Scheduling, evidence selection, and semantic judgment remain open.
