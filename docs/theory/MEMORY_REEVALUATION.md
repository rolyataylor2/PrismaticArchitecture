# Memory Re-evaluation

Memory re-evaluation is developmental reinterpretation by the current owning Part, not factual correction by an event archive.

```text
current subjective memory
        ↓
developmental pressure
        ↓
optional rare ancestor replay
        ↓
current Part reinterprets the experience
        ↓
proposed semantic mutation
        ↓
new memory version
```

Developmental pressure may include substantial Part development, repeated conflicting evidence, therapy-related activation, prediction failures, divergent memories descended from one event, unresolved contradiction, a changing Part role, or newly relevant Identity development. These are candidate signals, not permanent rules. Replay selection remains experimental; there is no fixed schedule.

The Part may retain, soften, intensify, or otherwise change its prior interpretation. Objective history provides evidence and context; the current Part supplies psychological meaning. An accepted revision creates a new immutable version, while prior versions remain preserved. Significant reinterpretation should be able to retain its relationship to the prior view (“I used to think X; now I think Y”) when meaningful, without requiring fixed wording.

Ordinary reconsolidation may occur through new evidence without objective replay. Older versions are historical/developmental context, not routine cognition input. Current subjective content remains directly retrievable without reconstructing it from objective ancestry.
