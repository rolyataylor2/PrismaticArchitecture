# Part Development

Parts develop by attempting to fulfill missions in a changing world.

```text
mission → strategy → prediction → Identity decision → outcome
→ Part evaluation → incremental belief / memory / strategy change
```

Changes may include better predictions, strategies, trigger sensitivity, confidence, reasoning, context, specialization, relationships, communication, urgency, and time horizon. Development is locally motivated, not necessarily toward global health; a protective Part may learn either careful trust or universal distrust.

Parts may develop metacognition about their performance and ask other Parts for information. Important changes should be historically reconstructable so the system distinguishes what a Part is from how it became that way.

A Part can learn even when Self rejects its bid. Outcomes provide evidence regardless of which Part's proposal was selected. External teaching, Self-mediated inquiry, alternative strategies, and observed results are valid developmental mechanisms; Self does not directly rewrite the Part.
