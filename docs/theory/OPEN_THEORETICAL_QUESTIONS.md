# Open Theoretical Questions

These questions are intentionally unresolved within the canonical boundaries.

- What represents emotional impact, mission adaptation, and Part cognitive sophistication?
- How do trigger patterns, retrieval, and activation evolve without making retrieval the definition of activation?
- What bid information is sufficient for Self mediation and Identity-guided selection?
- How should Part-selected prediction context, optional confidence, and conditional/time-based horizons be represented while preserving one outstanding prediction per Part?
- How do temporary Parts, Part development, and Identity development preserve continuity?
- What conditions cause an Identity mask to be removed or become genuine Identity development?
- When should Self use fast selection versus deeper questioning and mediation?
- What mediated information can Self receive without granting raw WorldState access?
- Which attention experiments are useful without inserting a mandatory post-bid filter?
- How can simulation, replay, and other environments provide controlled evidence without becoming cognition?
- When does a semantic change preserve identity versus create a successor Part?
- How should a Part decide which accumulated evidence remains active versus consolidated?
- How much raw subjective memory should be placed into one Part inference?
- When should a Part split rather than merely learn contextual strategies?
- When are two Parts similar enough to merge without losing useful disagreement?
- How should linguistic confidence interact with optional structured confidence?
- How should archived Parts influence later formation without directly bidding?
- How should the system distinguish temporary role evolution from permanent mission change?

## Activation graph

- How many waves of activation should be permitted?
- How should propagation decay?
- How should cycles terminate?

## Inhibition

- Should inhibition emerge primarily from candidate competition, explicit suppression, resource budgets, or combinations?

## Emotional charge

- How should charge change over time?
- Should it remain linguistic, become partially structured, or both?

## Self access

- Which recognition/context Parts should become visible to Self when they make no behavioral bid?

## Generalization

- How does consolidation choose among competing abstractions such as Paul, personal questions, strangers, coercion, and ignored boundaries?

## Memory reconsolidation

- Exactly when does new evidence become capable of modifying an existing subjective memory rather than merely creating another memory?

## Consolidation

- When should repeated co-activation cause update, new relational Part, new generalized Part, split, merge, or no change?

## Therapy

- What architecture characteristics are necessary for ordinary talk therapy to generalize outside the therapeutic context?

## Thought termination

- When does an activation cascade stop and become a sufficiently complete moment of cognition?
