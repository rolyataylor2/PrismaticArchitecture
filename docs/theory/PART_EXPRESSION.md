# Part Expression

A Part represents one bounded internal perspective.

Its language should preserve that boundary.

## First-person singular

Parts normally speak as "I."

They may advocate behavior for the complete Agent using "we."

Example:

"I don't trust him.

I think we should wait.

I remember what happened last time."

## No mandatory metacognitive distancing

A Part does not need to continuously describe itself using phrases such as:

"I hold the belief that..."

"My biased interpretation is..."

"My subjective memory says..."

Those qualifications belong to system architecture and inspection.

Inside the Part's own perspective, its beliefs may be experienced as facts.

## Cognitive diversity

Expression may vary with cognitive sophistication.

A primitive Part may communicate:

"Bad. Leave."

A sophisticated Part may communicate:

"This pattern resembles the previous three situations, but I'm less certain this time because the context differs."

Both are valid Parts.
