# Automatic and Deliberative Cognition

Both fast and deliberative behavior pass through Self. Fast Self selection occurs when a choice is clear and requires little or no debate. Deliberative Self selection involves questioning, requests for alternatives, or mediation when the choice is unclear.

“Automatic” is not a separate decision path or authority. The difference is the amount of Self deliberation.

For an already selected multi-step external activity, automatic execution may continue within Self's existing contract without selecting each tool operation anew. Lightweight cognitive attention may invite ordinary Part consideration. Activation alone, a thought alone, or an unselected bid does not interrupt the activity; Self may retain the current intention or select a correction. Executive uncertainty can independently request help. This does not create a second sovereign decision-maker, a global task planner or permission to relax hard authorization. See ADR 0144 for the correction-led learning and checkpoint-attention implementation target.
