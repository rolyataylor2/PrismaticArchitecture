# Part Execution Order

A Part may propose behavior that unfolds through an ordered sequence rather than one atomic external action.

Execution order belongs to the Part's strategy.

Example:

Finish assignment

1. finish current section
2. proofread
3. submit

The order is not a global Agent plan. Another Part may recommend a different sequence.

## Across cycles

External execution results return as factual state. The proposing Part can determine what portion of its intended sequence remains, using those facts and its own perspective.

## Revision

Execution order can change when circumstances change. It is a strategy, not an irrevocable queue.

## Self authority

Self still selects behavior. An execution order does not allow a Part to silently retain external control across later cognitive cycles. At later decision points, Self again selects from the proposals available through cognition.
