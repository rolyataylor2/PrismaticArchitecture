# Self Runtime

Self is the unmotivated selection and mediation process of the complete Agent. Parts receive and interpret WorldState; Self does not directly perceive WorldState.

Self receives Part bids, explanations, disagreements, predictions, answers to questions, persistent Identity, and temporary Identity masks. It has no independent mission or independent outcome optimization. It asks: “Which available proposal best serves the Identity I am responsible for expressing?”

If unclear, Self may question Parts, request alternatives, ask them to respond to one another, or mediate debate. It must not resolve uncertainty by reading raw WorldState. Self may help Parts learn but does not directly rewrite Part state. Identity is the persistent reference; Self is the chooser; the selected action is handed to an external interface for execution.

ADR 0112 supersedes single-candidate arbitration: world-blind Self scores current bids, then conservatively selects a small compatible set by scoring marginal value against all already selected bids. Each action retains its proposing perspective and original execution order. Internal inquiry remains a separate, singly selected path.
