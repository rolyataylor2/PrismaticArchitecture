# The Prism Agent Architecture Parts Architecture

Parts are persistent, bounded cognitive perspectives that develop through experience, not disposable prompts or complete autonomous agents.

## Cognitive cycle

WorldState → Activator retrieval/activation → activated Parts → interpretation/emotion/predictions/proposals → bids → Self selection using Identity → external execution handoff → outcome → later prediction evaluation → adaptation → lifecycle changes.

This describes responsibilities, not a required algorithm. Parts influence behavior but do not own it. Formation, adaptation, dormancy, reactivation, splitting, merging, and archival preserve history and lineage. Simulation is an optional external environment that may supply WorldState; it is not part of normal cognition.
