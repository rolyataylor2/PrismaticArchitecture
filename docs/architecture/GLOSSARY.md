# OntoAgentic Glossary

## WorldState

Objective fact-based external information. It contains no Agent goals, psychological meaning, desired outcomes, or action preferences.

## Activator / Retrieval / Trigger

The Activator matches WorldState against Part trigger patterns. Retrieval may reduce the candidate set as an optimization; it does not decide activation.

## Part / Bid

A Part is a persistent, motivated, bounded perspective. Activated Parts interpret WorldState, react emotionally, forecast, and propose. A bid is its structured advocacy to Self.

## Identity / Self / Executive

Identity is persistent self-definition. Self is the temporary unmotivated selector and mediator that reads Identity and chooses among bids. The Executive enacts Self's choice.

## Attention / Automatic cognition

Attention is experimental and non-canonical after bidding. Automatic cognition means fast Self selection, not a bypass of Self.

## Simulation / Environment

Simulation is an optional external environment and training system. It may supply WorldState and receive actions; it is not part of the Agent engine.
