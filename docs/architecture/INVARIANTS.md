# Architectural Invariants

## Executive authority and learning (ADR 0140)

ADR 0144 extends the Executive target with correction-led conditional learning and lightweight checkpoint attention. Activation permits considering intervention; competence independently permits requesting guidance; only Self-selected corrections change ongoing intent. Hard authorization gates remain independent. Procedural knowledge must not freeze historical preferences. Read-only skill inspection may expose recorded bid/thought/activation lineage to researchers, never as direct Self/audit access. Exact procedure support remains a compatibility foundation rather than completion of this target.

The external Executive receives immutable Self-selected contracts. Framework permissions remain outside swappable runtimes. Operational retries, planning and procedural skills cannot change selected goals, grant capabilities or mutate psychology. Compact factual feedback enters later original-thread snapshots; the detailed ledger is an audit resource, not shared autobiographical memory. Validated, versioned procedures may be taught through ordinary cognition; Executive uncertainty never selects Parts or determines their psychological learning. See [ADR 0140](decisions/0140-bounded-teachable-executive.md).

No-submission guidance continuation requires a fresh Self-selected supplemental contract and once-only recorded request consumption. The original action/request stay immutable, and the original chain's guidance budget cannot increase. Public selected-intent request contexts are bounded original-thread observations, not private Part state, WorldState goals or factual completion evidence; Self remains world-blind. See [ADR 0142](decisions/0142-selected-guidance-continuations.md).

Explicit selected teaching checks actual recorded tool evidence after outcome persistence. Both captured/current learning modes constrain activation; a passed check may remain a supervised proposal. Teaching errors never erase real operational outcomes. Public procedure manifests expose declared competence and limitations without raw method payloads or private Part state. Known-method invocation preserves its selected action and captures a scoped immutable method/version under current grants and intersected budgets. One-time instruction bindings do not become reusable authority. See [ADR 0143](decisions/0143-selected-procedure-teaching-and-use.md).

## Current default revision (ADR 0126)

[ADR 0126](decisions/0126-constructed-perspectives-and-dispositions.md) supersedes older persistent-Part and private-only recall guidance for the default constructed architecture. Parts are temporary working perspectives reconstructed from subjective Agent autobiography; retired instances remain inspectable. Thread steering and gated entity-bound disposition graphs guide perception and recall. Self remains world-blind and Identity-guided; execution remains external. ADR 0128 removes the earlier online flow from application code. Historical regression fixtures and offline Part-development consolidation remain separate.

These are properties that should remain true regardless of implementation. A proposed implementation that violates one should be treated as an architectural change rather than a normal refactor.

## Cognitive identity

A Part is not an LLM request, provider, or tool-using autonomous agent. A complete Agent is not synonymous with a model session.

## Authority

Individual Parts do not directly perform externally consequential actions. The complete Agent retains one external locus of action authority. Activation does not automatically grant authority. A strong bid does not itself perform an action.

## Simulation and world state

Simulations create experiences; Agents create psychological meaning. Simulation code must not directly manipulate Part state, activation, cognitive bids, identity, or psychological memory. The same simulated event must be capable of producing different cognitive consequences in different agents.

Authoritative simulation reality is distinct from agent belief. An agent may believe something false, and the world may contain facts it does not know. Generated narration does not become authoritative merely because it was generated.

## Providers, routing, persistence, and history

Provider-specific details must not define cognitive identity. The same persistent Part should be capable of being evaluated using different models.

Routing chooses computational resources; it does not determine motivation, psychological interpretation, or external action.

Presets describe starting conditions; persistent state describes what an entity has become. Do not silently overwrite presets as an agent develops.

Dormancy and archival do not erase developmental provenance. Splitting and merging preserve ancestry. History is a domain concept and must not be reduced to source-code Git history.

## Inspection and modularity

Important cognitive decisions should eventually be observable through structured information. Critical architecture must not depend exclusively on unstructured logs or hidden prompt contents.

Simulation engines, provider layers, storage implementations, model providers, and Parts-management policies should remain replaceable. Avoid hidden dependencies that make replacement impossible.

## Identity authority

Self has final selection authority for the complete Agent while reading Identity as persistent self-definition. The Executive enacts Self's selected behavior. Parts may influence selection but do not automatically override it.

## Internal plurality

Parts are not required to be individually balanced, objective, socially appropriate, or globally optimal. Internal heterogeneity is intentional.

## Mission bias

A Part may be systematically biased toward its mission. This bias is part of its cognitive function rather than automatically an implementation defect.

## Cognitive diversity

Parts are not required to possess identical reasoning capability. Cognitive sophistication may vary between Parts and may develop over time.

## Perception

Self does not receive WorldState directly. Parts are the canonical psychological interpreters of WorldState; any additional cognitive access must remain explicitly mediated through Parts or another defined mediated interface.

## Subjective memory

There is no requirement for one canonical internal autobiographical transcript. Parts may maintain conflicting subjective memories. External factual records and subjective memory are different concepts.

## Objective experience is not ordinary memory

World/audit experience history must not become a perfect autobiographical memory available to ordinary cognition. Objective history is available for inspection, research, ancestry verification, and explicitly controlled developmental replay; ordinary Part recall does not automatically dereference it.

## Digest first

Parts should normally reason from their persistent subjective memories, beliefs, relationships, and other psychological products of experience. Ordinary consolidation primarily processes these digested traces rather than rereading the objective event archive.

## Rare reopening

An objective ancestor experience may be reopened only through an explicit developmental mechanism. Such replay is exceptional, selective, and traceable; selection criteria remain experimental.

## Subjective authority

Objective replay may provide evidence, but the current owning Part supplies psychological meaning. Objective records do not dictate a corrected interpretation or force memories to converge.

## Memory continuity

Significant reinterpretation should preserve developmental continuity where psychologically meaningful. Prior memory versions remain immutable, and a current version may relate its present view to an earlier one.

## Self memory boundary

Self may not inspect objective ancestor experiences to adjudicate disagreement between Parts. It may ask Parts to explain their perspectives through ordinary mediation.

## Memory privacy

Parts must not automatically gain transparent access to all other Part memories. ADR 0125 permits explicit references to Agent-owned subjective records; absent references preserve legacy originating-Part access. This does not share private beliefs or other Part state, and source WorldStates remain provenance rather than ordinary recall.

## Incremental development

Persistent Part state should not ordinarily be destructively rewritten as one atomic personality replacement. Development should preserve continuity and reconstructable change.

## Temporary specialization

Not every formed Part is expected to persist. Task-oriented Parts may naturally cease active participation after their mission resolves.

## Emotional completeness

The framework must not architecturally exclude particular human affective perspectives merely because they are uncomfortable or negatively valenced.

## Self mediation

During Self integration, the temporary whole-agent perspective may influence Part learning through inquiry, evidence, experimentation, and observed results. Identity remains the persistent self-definition. Neither automatically imposes belief revision.

## Identity self-definition

Identity represents a persistent self-definition and is not merely another outcome-optimizing Part.

## Proposal-space constraint

Self chooses from proposals made available through cognition using Identity. Self may request additional proposals but is not an unexplained source of perfect actions.

## Congruence

Behavior and Identity may conflict. The framework preserves self-incongruity as meaningful state rather than automatically forcing behavior or Identity into agreement.

## Identity development

Identity is persistent but not immutable. External systems must not directly rewrite it; changes arise through mediated cognitive development.

## Environmental shaping

Environmental feedback affects cognition through experience. The environment must not directly program internal personality state.

## Cycle consistency

All Parts evaluating one cognitive decision use the same immutable WorldState snapshot.

## Activation optimization

Approximate retrieval may narrow candidate Parts but does not determine psychological activation.

## Shared factual context

WorldState may be shared and cached across Parts. Under ADR 0093, attributed prior cognitive thought text is explicitly shared with decaying retention; its subjective content is not external truth. Part-private beliefs and other psychological state may not be shared. Subjective memories may be shared only through explicit ADR 0125 references. Full thread chat records are external context, not autobiographical memory.

## Cache boundary

Inference caching must never give a cognitive subsystem information it would not otherwise be permitted to access. In particular, Self must not gain WorldState through cache reuse.

## Cache transparency

A cached inference context must be cognitively equivalent to processing the same permitted context without caching. Caching changes cost and latency; it must not change psychology.

## Language-first Part state

Part development must preserve semantic beliefs, missions, memories, strategies, and interpretations. Structured values may support operations but must not become the sole representation of psychological change.

## Relational subjectivity

Part memories and beliefs may preserve incompatible positioned interpretations of experience. Objective WorldState and external records do not automatically rewrite subjective Part memory.

## Versioned development

Accepted persistent Part changes are incremental, identifiable, and historically reconstructable. Rollback, consolidation, splitting, merging, archival, and reactivation preserve relevant history and ancestry.

## Runtime neutrality

Persistence, indexing, scheduling, validation, patch application, and versioning must not invent psychological meaning. Semantic lifecycle decisions belong to cognitive inference.

## Model-role separation

Bounded decision models judge. Generative models reason. Runtime code orchestrates.

## Activation independence

Candidate Parts are evaluated against shared WorldState context, while each receives its own independent graded activation Score. Parts do not compete for a single activation slot, and activation values are not normalized across candidates.

## Bounded Self choice

Self can select only proposals produced by Parts, or surfaced primitive cognition (ADR 0104), or request `DELIBERATE`. Primitives have no memories or predictions; Self remains world-blind.

## World blindness

Neither Jev Self arbitration nor generative Self deliberation receives raw WorldState.

## Probability semantics

Decision-model probabilities represent semantic judgment uncertainty. They are not automatically psychological quantities.

## Infrastructure failure

Model/provider failure must remain distinguishable from psychological cognition.

## Relational specificity

Person-specific relational information should not remain embedded indefinitely in unrelated generalized Parts when a dedicated relational representation has formed.

## Provenance isolation

Historical origin information must not automatically participate in current activation retrieval.

## Activation propagation

Part cognition produces no activation cues. Attributed retained thoughts may expand candidate consideration and influence independent activation scoring only on a later immutable snapshot (ADR 0098).

## No raw-prose priming

Do not inject private Part state or unrestricted private monologues into other Parts. ADRs 0093 and 0098 permit attributed, decaying expressed thoughts through later WorldState snapshots.

## Recognition without bidding

An activated Part may provide recognition or context without proposing external behavior.

## Conservative consolidation

Offline cognitive restructuring should prefer preserving existing distinctions when evidence for structural change is weak.

## Task persistence

Task persistence belongs to Parts through mechanisms such as stickiness and ongoing strategy. Do not add an Agent-wide task goal merely to preserve continuity. Stickiness preserves candidate consideration while a concern remains unresolved; it is distinct from activation, emotional charge, bid strength, and authority.

## Execution order

A Part may maintain an ordered behavioral strategy. This does not grant the Part continuous external control and does not create a global plan. Self remains the chooser at later decision points.

## External execution

External action execution belongs outside the psychological architecture. The Prism Agent Architecture selects behavior and hands it off to the appropriate external interface. Execution status may later return as objective WorldState facts.

## Automation boundary

Generic automated tasks and background job systems are not part of The Prism Agent Architecture cognition. Prediction evaluation scheduling remains part of Part learning and is not equivalent to task automation.

## Therapy parity

Therapeutic conversation must interact through normal Agent interfaces and cognitive processes. It must not receive privileged Part mutation authority.

## One open prediction

A Part may normally carry only one unresolved prediction.

## Prediction continuity

New evidence should continue, revise, resolve, invalidate, or abandon the current prediction rather than continuously stacking forecasts. Revisions preserve prior versions.

## Prediction context

Committed predictions preserve Part-selected experiential context while relevant context is available (full thread chat and decaying shared thoughts under ADR 0093); they do not copy the complete WorldState.

## Prediction breadth

Predictions are not restricted to behavioral bids or paired selected/non-selected forecasts.

## Waking episodic encoding

Meaningful prediction outcomes may form subjective episodic memories during waking cognition; sleep later consolidates them.

## Waking memory formation

Under ADR 0098, ordinary waking memory formation occurs only through prediction outcome reflection. Offline development and explicit researcher operations remain separate paths; prior memories remain preserved.

## Spike distinction

Activation spike, activation level, emotional charge, stickiness, and prediction confidence remain distinct. A spike may be supplied to its owning Part and may invite prediction/encoding, without fixed thresholds or automatic consequences.

## Motivated relational descriptions

Part names express feelings or motivations in fewer than six words when authored or renamed. Missions express the Part's view of what serves the Agent; strategies and driving relational beliefs remain distinct. Generalized Parts use broad subjects; specific relational Parts may retain their referents. Runtime validates representation but does not invent ego-centric motives or erase developmental history to enforce semantic style. See ADR 0092.

## Cognition products

Under ADR 0098, Part cognition returns only interpretation, thought, evidenceSummary and an optional proposal. Ordinary waking memory formation and persistent Part mutation occur through prediction outcome reflection, not the cognition result.

## Identity Trait continuity

Identity content has no fixed psychological categories: authored question-and-answer Traits provide persistent self-definition. Editing a Trait preserves its ID and creation timestamp; duplication assigns a new ID and creation timestamp. Deletion and migration preserve previous Identity versions. Keywords support context search without granting cognitive authority or access (ADR 0099).

Identity Trait roles (ADR 0101): only `self_definition` Traits are supplied to Self. `autobiographical` Traits are researcher-authored background stored alongside self-definition, not authoritative autobiography or shared Part memory. Runtime filters them before arbitration and deliberation; no Part access is added.

## Continuous primitive appraisal

All configured primitives are independently scored alongside candidate Parts against the same immutable snapshot, then separately filtered by editable thresholds. Identity temperament affects primitive appraisal only. Part correctness, Identity alignment and maturity do not determine Part activation. Primitive scores and subjective outputs are not authoritative world truth or automatic Part mutation instructions.

## Quality-guided deliberation (ADR 0105)

Self chooses an existing bid or `DELIBERATE`. One ordered, world-blind inquiry generation selects a primary and optional supporting C quality before identifying missing information, targets and one question. Qualities are not choices or motivations. Selected Part inquiry bids use their original targets and question. Participants answer and retain, replace or withdraw their own current bid in one generation; other bids remain unchanged. Attributed responses return to the same bounded arbitration. See [ADR 0105](decisions/0105-quality-guided-self-deliberation.md).

## Optional post-deliberation activation (ADR 0108)

The per-Agent `reevaluateAfterDeliberation` switch defaults to false. When enabled, completed inquiry responses enter a new immutable, attributed subjective snapshot before activation is re-evaluated. Remaining active contributors retain bids; newly active contributors generate cognition; inactive contributors leave Self’s choice set. Self remains world-blind and ordinary deliberation limits apply. See [ADR 0108](decisions/0108-post-deliberation-activation.md).

ADR 0110: Self choice receives complete mediated contribution and inquiry history for the cycle, with only current bids selectable. NOTHING is available only after two completed deliberation rounds. Self remains world-blind; historical contributions confer no renewed action authority.

## Score-based Self selection (ADR 0112)

Self arbitration now uses graded Scores and conservative marginal set selection, superseding single Choice arbitration. Only mediated current proposals are selectable; Identity guides and Self remains world-blind. See [ADR 0112](decisions/0112-score-based-self-selection.md).

## External speech realization (ADR 0113)

The chat Executor realizes selected consecutive Say commands through the Agent-selected generative provider using only selected intentions and speech-tagged Identity Traits. This is expression, not arbitration. Original proposals remain preserved, while speech text and source IDs record what was actually emitted. Self remains world-blind. See [ADR 0113](decisions/0113-identity-guided-speech-realization.md).

Explicit permanent researcher deletion of a complete Agent is an administrative exception to history preservation (ADR 0115). Ordinary updates, rollback, archival and cognitive development continue to preserve immutable history.

ADR 0118 restricts prediction reflection to subtle append-only beliefs, mission-serving strategies, and How I think nuances. Part names and missions remain unchanged. Confidence shifts are tiny and linguistic; subjective beliefs may be false or formed from trusted testimony. Runtime preserves existing entries and rejects other prediction-driven Part edits.

ADR 0120 supersedes linguistic-only prediction confidence: Parts start at 100% beliefConfidence, gain 1 percentage point per correct resolved outcome and lose 5/12 point per incorrect one, clamped to 0–100%. Predictions support existing beliefs and inherit current Part confidence; subjective thoughts retain conviction. Additive learning and unchanged names/missions remain enforced.

ADR 0123 adds independent JEV subjective-memory recall and selectable memory-based Part candidate discovery. Recall uses current explicitly referenced stored contents (legacy originating-Part fallback under ADR 0125), timestamps and functional relevance; cross-owner scanning is scorer-only, followed by ordinary Part activation. Self and primitives gain no memory access. Operational recall threshold/count are configurable; existing version history is preserved.

## Ordered generation boundary (ADR 0131)

Construction, independent subjective memory evidence and initial cognition may share one ordered generative request. Runtime validates scope, memory IDs, unique continuation and unresolved predictions before committing products. Different disposition/entity bindings remain independent, and Self receives only mediated outputs.

Researcher disposition deletion appends a tombstone version and removes the disposition from live listings, activation and consolidation inputs while preserving saved versions and references. Researcher rollback appends a new current version from a selected historical disposition; it never erases intervening history. These administrative operations grant no cognitive authority.
