# ADR 0022: Self-Incongruity Is Developmentally Meaningful

## Decision

Conflict between Identity and available behavior is meaningful cognitive state.

## Reason

A persistent mismatch between desired Identity and enabled behavior can create pressure for growth.

## Consequences

The framework must not eliminate incongruity by rewriting Identity or generating artificially harmonious behavior. Incongruity may contribute to introspection, Part formation, strategy development, or Identity revision.

## Flexible implementation

No permanent congruence metric is defined.
