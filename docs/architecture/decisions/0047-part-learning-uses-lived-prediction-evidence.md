# ADR 0047: Part Learning Uses Lived Prediction Evidence

## Decision

Parts learn partly by comparing predictions and proposals with later outcomes. Evidence changes Parts locally; no global reward function is required.

## Reason

The same outcome may have different developmental meaning for different Parts.

## Consequences

Prediction records should preserve proposals, expected outcomes, timing or conditions, actual results, and the Part's interpretation of the result.

## Flexible implementation

Evidence representation and optional numerical measures remain open.
