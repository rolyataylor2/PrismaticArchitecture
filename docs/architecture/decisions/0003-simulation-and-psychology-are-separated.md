# ADR 0003: Simulation and Psychology Are Separated

## Decision

Simulations create experiences. Agents create psychological meaning.

## Reason

The same external experience must be capable of producing different developmental outcomes in different agents. Otherwise the simulation would predetermine the psychological result being studied.

## Consequences

Simulation systems do not directly manipulate Parts, cognition, identity, activation, or psychological memory.

## Flexible implementation

The interface connecting simulations and Agents remains open.
