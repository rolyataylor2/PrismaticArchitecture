# ADR 0055: Self Debate Is a Separate World-Blind Reasoning Loop

## Decision

When arbitration requires deeper inquiry, Self uses a generative reasoning stage that still has no WorldState access.

## Reason

Self must be able to question and mediate Parts without becoming an independent environmental interpreter.

## Consequences

Self asks Parts for clarification. Parts retain WorldState access and return psychologically situated answers. Arbitration repeats afterward.
