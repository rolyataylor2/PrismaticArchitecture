# ADR 0075: Subjective Memories Retain Opaque Event Ancestry

## Status

Accepted

## Context

Subjective memory development benefits from inspectable provenance, but provenance must not imply that an ordinary memory retrieval reads the original event.

## Decision

Part memories may retain stable, opaque references to one or more ancestor experiences. A reference ordinarily establishes descent only. It does not automatically dereference objective event contents.

## Consequences

Ancestry can support provenance, research, controlled replay, and structural verification. Different Parts may retain distinct memories descended from the same event without being normalized. Verification of shared ancestry does not decide emotional meaning.

## Related decisions

ADR 0045 requires explicit versioning; ADR 0060 separates provenance from activation; ADR 0074 separates objective experience from ordinary autobiographical memory.
