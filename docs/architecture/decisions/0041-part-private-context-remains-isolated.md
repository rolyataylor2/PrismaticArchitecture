# ADR 0041: Part-Private Context Remains Isolated

## Decision

Only shared factual context may be freely reused across Parts. Part-specific beliefs, subjective memories, missions, strategies, and developmental state remain private to that Part.

## Reason

Cross-contaminating Part context would destroy the independence of their perspectives.

## Consequences

Caching mechanisms must distinguish shared context from Part-private context.

## Flexible implementation

Physical cache layout remains open.
