# ADR 0079: Significant Memory Reinterpretation Preserves Continuity

## Status

Accepted

## Context

Version ancestry preserves machine history, but significant psychological development may also depend on the Part's current account retaining a relationship to what it once believed.

## Decision

Current subjective memory may preserve its relationship to prior interpretations when psychologically meaningful. Significant reinterpretation should be capable of expressing continuity, such as “I used to think X; now I think Y,” without forcing this wording on every mutation. Previous versions remain immutable.

## Consequences

Machine version ancestry and psychological continuity are distinct and useful. Older versions remain developmental context and are not automatically supplied to ordinary cognition.

## Related decisions

ADRs 0017 and 0045 require incremental, versioned change; ADR 0072 allows memory reconsolidation.
