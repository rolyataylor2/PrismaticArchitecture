# ADR 0127 — Researcher-authorized legacy cutover

Status: Accepted

The researcher explicitly permits discarding legacy Parts and logs for the ADR 0126 conversion. This is a one-time administrative cutover, not psychological forgetting or a cognitive API. Preserve Identity, provider configuration, researcher settings and subjective memory versions. Append memory versions removing obsolete recall references; formation attribution and ancestor IDs remain opaque provenance when their legacy records are discarded.

Only a wholly legacy Agent may be reset. Refuse an Agent containing constructed instances, steering or dispositions, or work currently executing. This keeps the retention guarantee for every new constructed Part and its inspection history. Conversion sets constructed architecture explicitly. Ordinary new memory creation still requires a real owning Part; subsequent versions may retain a discarded formation ID only when preserving an existing same-Agent record in constructed mode.

The reset transaction removes legacy Parts, predictions, worlds, cycles, audit logs, executions, consolidation and experiment records. Identity and memory histories are not rewritten. No third-party source or credentials are touched.
