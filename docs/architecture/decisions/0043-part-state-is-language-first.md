# ADR 0043: Part State Is Language-First

## Decision

Part psychology is primarily represented semantically. Structured machine data supports but does not replace language-level beliefs, missions, memories, strategies, and interpretations.

## Reason

Meaningful development can occur through changes in wording, specificity, conditionality, and interpretation without requiring a scalar reinforcement value.

## Consequences

Runtime structures may support retrieval, scheduling, provenance, and inspection, but must preserve semantic content as a first-class representation.

## Flexible implementation

Optional numeric confidence, intensity, embeddings, and other measurements remain experimental rather than foundational.
