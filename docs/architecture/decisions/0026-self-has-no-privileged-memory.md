# ADR 0026: Self Has No Privileged Memory

## Decision

Self does not automatically access an objective autobiographical record.

## Reason

Subjective memory belongs primarily to Parts. Ground-truth recall would erase perspectival memory and meaningful uncertainty.

## Consequences

Self reconstructs the past from available Part memories and optionally accessible external evidence. Developer audit history remains distinct.

## Flexible implementation

Memory retrieval and reconstruction mechanisms remain open.
