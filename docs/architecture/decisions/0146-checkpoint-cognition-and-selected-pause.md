# ADR 0146: Checkpoint cognition, continuation and selected pause

Status: Accepted implementation target extending ADRs 0144/0145.
Date: 2026-10-08

Opt-in interested-checkpoint review runs the ordinary Agent pipeline against the checkpoint's identical immutable WorldState and runtime-issued activation assessment. It uses normal eligibility, scoped recall, independent ordered Part generation, prediction evidence, bounded deliberation/recruitment and coverage. It is not a separate automatic-action agent or privileged teacher. A checkpoint promoted to `attention_review` records real cognition; background/monitor-only records remain distinct and do not age thoughts or replace posture.

Only a still-running attributed activity is reviewed automatically; completed/failed activity cannot recursively launch another execution review. Relevance or a competence gap invites cognition but confers no selection authority. With no bid, expressed thoughts/predictions are retained and execution continues without mandatory Self deliberation. With bids, world-blind Self receives ordinary expressed products and a narrow mediated description of the previously selected activity: opaque execution reference, expressed goal, success criterion and declared constraints. No observation, tool argument/result, activation score, competence estimate, private Part state or raw audit contract is added to Self context.

Self may exclusively choose `CONTINUE_EXECUTION` immediately when that selected activity context is present. This creates no new tool contract, confirms no outcome and changes no permission. Ordinary external proposals remain separate intentions; they do not implicitly cancel the existing activity. A Part may explicitly propose `operation.intervention` to pause the referenced current activity. This is a one-time execution-control directive, incompatible with tools, verification, skill invocation, teaching or supplemental guidance in that same proposal. It cannot become reusable procedural authority.

The framework compiles pause authority separately from MCP tool authority. The host independently checks a recorded Self-selected, nonfailed same-Agent/thread contract and a current same-Agent/thread operational target; it atomically consumes the directive once and stops the locally owned worker. It preserves the original contract, tool ledger and actual parent outcome. Cancelling an in-flight result remains unverified; stopping future local submissions does not undo earlier effects or assert external-world completion. A completed pause reports that local work has stopped, separately from the parent's verification status. Missing local ownership, expired targets and repeated consumption block without tool authority. Receipt evidence is required for reported pause completion. Restart never recreates workers or resumes an interrupted segment.

Inspection records review start, thoughts-only/continuation/selected outcomes and requested/confirmed intervention lineage. A selected pause is not evidence that the Part was correct or that the original goal succeeded. Replace/modify/resume after submitted effects, full correction-led conditional consolidation, maturity and configured-model transfer observations remain required ADR 0144 work; this decision does not declare the original Executive thread complete.

## Explicit external consultation

The external host may explicitly request ordinary cognition for a currently running selected execution, independently of automatic monitoring configuration and thresholds. It supplies bounded attributed observations and a reason, which become part of one immutable WorldState shared by Parts. The request and reason are preserved as audit lineage. Independent activation remains ordinary: requesting cognition neither activates a particular Part nor dictates a bid or Self decision. The request reason and raw observations do not enter Self directly. Existing mediated selected-activity context and fresh selected authority remain required for intervention.

Explicit consultation is serialized with ordinary Agent inference. Ownership and current activity are checked when admitted; an activity ending during assessment does not receive an ongoing-activity review. The response distinguishes review from activity ending before review. Consultation does not automatically suspend execution, reset budgets, retry tools or acquire a worker handle. A replacement external loop decides when to wait for this host call while preserving its existing authorization gates. Existing inference roles and access boundaries are unchanged; no separate consultation model or prompt task is introduced.
