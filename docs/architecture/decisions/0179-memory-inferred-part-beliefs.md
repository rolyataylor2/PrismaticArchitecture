# ADR 0179: Part beliefs fill gaps from recalled memory

Status: Accepted, 2026-10-24. Source: researcher clarification after inspecting the food-search room: a Part may abstain when direct evidence contradicts its proposed belief, and forms a belief only when direct evidence is absent and inference from past memories is needed.

Extends ADRs 0133/0136/0165 and narrows earlier permission to express any experienced interpretation in the assembled Part's `beliefs` list. Current observations belong in WorldState and the Part's interpretation/evidence summary. A belief is a subjective inference from accessible recalled memories addressing a gap in current direct evidence. It is not a duplicate perception, a desired outcome, a preserved assertion merely because it existed in a previous Part version, or an imagined future treated as occurrence. A contradicted carried belief may be withdrawn without a replacement; empty belief lists are valid.

Scope continuity remains unchanged: code can supply continuity from the continuing working Part, disposition, recalled memories and immutable current WorldState to formation, but excludes the previous belief list from generation input. The projected prior working state has `beliefs: []`; the stored prior version is unchanged. Formation and cognition reconsider beliefs against that experience. This decision does not make every cycle a blank new instance, delete historical versions or automatically certify observations as objective truth. Current contradictory evidence permits abstention and withdrawal rather than mandatory reconciliation into another confident belief. Uncertain interpretation, affect, motivation, prediction and action advocacy remain available without a belief.

The request-specific output schema and runtime both require empty formation/cognition belief lists when no past memory was recalled. Previous working state, Identity, disposition text and prediction capsules do not substitute for currently recalled memory. This enforces an accessible evidence prerequisite without having code decide psychological meaning. With recalled memories present, inference remains generative: identify the evidence gap, use that memory, and abstain where direct evidence already answers or contradicts the proposed belief. The current string-list format is retained; it does not prove per-belief causal grounding or semantic compliance. Audit outputs and paired observations are required before claiming those properties.

Preserve original failed trials and old Part versions. Re-forming a continuing Part can produce an empty current belief list; no migration, retrospective rewrite, blanket truth repair or forced disposition is introduced. Schema violations are infrastructure failures, never silently filtered into valid psychological output. Prompts, versions, task descriptions and mocks must match. Add Simulation Tests contrasting directly observed availability/absence with an occluded setting where recalled memory may support an explicitly uncertain inference. Mock fixtures establish contracts only; ordinary model outputs determine formation, reflection, predictions, dispositions and bids. Missing recalled memories mean an inference opportunity is unobserved. These experiments do not establish human psychology or clinical validity.
