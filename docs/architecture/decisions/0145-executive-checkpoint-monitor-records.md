# ADR 0145: Executive checkpoint monitoring records

Status: Accepted implementation increment toward ADR 0144; full attention/intervention integration remains required.
Date: 2026-10-08

Disposition eligibility and independent direct/associated activation can be evaluated separately from recall, Part assembly and generation. This read-only assessment uses one immutable snapshot and the ordinary disposition definitions, prior-cycle prediction attention and frozen association signals. It cannot retire/create Parts, form predictions, rewrite memory or select behavior. Ordinary assembly may reuse only an assessment issued by that same runtime for that identical snapshot and thread; an arbitrary supplied score is not an admission capability.

A checkpoint captures a new persisted immutable WorldState attributed to an `attention_monitor` cycle. These records preserve external observations and activation evidence without pretending that a Part or Self considered them. Monitor-only cycles do not age cognitive thoughts or replace the last expressed remembered interpretation/posture. They remain chronological external evidence for later ordinary cognition. Normal cycles and monitor inference are serialized per Agent in the application; this is inference coordination, not a global goal/task manager.

Monitoring is opt-in external configuration. Its implemented controls are independent relevance threshold, competence/coverage thresholds for explicitly attributed operational assessments, relevance hysteresis, advisory cooldown and allowed checkpoint events. Unknown competence/coverage remains unknown rather than being inferred from low activation. Repeated unchanged observations can suppress advisory review; materially changed evidence or an independent competence/coverage gap can request review. Hard authorization gates remain outside and cannot be suppressed. The monitor records `background` or `interested` and reasons, never `intervention` before an actual Self-selected correction.

Actual tool-result checkpoints are queued after trace persistence, without awaiting cognitive inference in the tool gateway or delaying the remaining selected strategy. No raw tool payload becomes a factual observation or Self context. Current original-thread execution attribution and tool-status summaries enter the monitor snapshot. Explicit environmental observations use the same narrow host entrypoint. Terminal reports, changed permissions, failures and unknown outcomes retain their separate existing operational meanings. Restart preserves assessments but never restarts a worker or tool submission.

This increment does not claim that an interested monitor record already invokes Parts or changes execution. Reusing its snapshot/assessment for ordinary cognition, mediated Self continuation, selected interventions, comprehensive competence/novelty inference, idle monitoring and conditional skill consolidation remain required ADR 0144 work. Factory activation prompts and Settings descriptions must accurately describe read-only relevance scoring; no primitive voices or new generative task are introduced by monitoring.
