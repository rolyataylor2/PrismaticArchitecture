# ADR 0111: Public inquiry target directory

Status: Accepted
Date: 2026-10-01

Activated Parts receive the names and IDs of available contributors in their current cognitive phase, solely for addressing proposed inquiries. No other Part state, beliefs, memory, bids or Identity is added to first-pass context. Answer generation receives the current available directory. Internal inquiry proposals and replacements use provider schemas restricted to these IDs; duplicates are rejected. Part-proposed questions and targets remain intact, with no semantic guessing or automatic retargeting. Runtime validation remains the final boundary. Legacy contexts without a directory can address only their owning Part.

Factory cognition and answer prompts and Settings variable inspection expose this directory. Self choice remains focused on Identity-guided selection. Stored failed cycles are preserved.
