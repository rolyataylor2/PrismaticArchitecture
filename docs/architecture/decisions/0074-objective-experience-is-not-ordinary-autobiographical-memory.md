# ADR 0074: Objective Experience Is Not Ordinary Autobiographical Memory

## Status

Accepted

## Context

Objective world or audit history can be more complete than any Part's lived account. Making it routinely available during recall would turn it into a hidden perfect autobiography and flatten relational reality.

## Decision

Objective experience records remain separate from subjective Part memory and are not normally available during recall. They may support inspection, research, verification, and explicitly controlled developmental replay. Ordinary cognition uses current subjective memory directly. Self may not inspect objective ancestor events to adjudicate Part disagreement.

## Consequences

Objective records can be historically available without being psychologically operative. External information reached through ordinary interaction becomes experience rather than invisible omniscience.

## Related decisions

ADR 0016 assigns subjective memory to Parts; ADRs 0026 and 0033 limit Self access; ADR 0044 preserves relational reality; ADR 0062 selects lived cognitive traces for consolidation.

This decision narrows the earlier ADR 0016 consequence that allowed Self to consult accessible external records during reconstruction: Self's current integrative context may contain Part reports and mediated subjective memories, but not objective ancestor-event history for adjudication.
