# ADR 0044: Part Memories Represent Relational Reality

## Decision

Part memory records the world from that Part's own constructed perspective. Different Parts may retain incompatible relational accounts.

## Reason

Subjective memory is part of a motivated perspective, not a neutral copy of external history.

## Consequences

The system must not force Part memories into one objective autobiographical transcript. External evidence may challenge a memory without automatically rewriting it.

## Flexible implementation

Memory content, metadata, retrieval, and revision mechanisms remain open.
