# ADR 0021: Parts Define the Candidate Option Space

Status: Superseded in its selection-authority wording by ADR 0034.

## Decision

Externally actionable proposals are generated through Parts and cognitive processes. Self selects among the options made available to it while consulting Identity.

## Reason

This preserves meaningful cognitive limitation: an Agent can fail to discover a good solution and later learn better strategies.

## Consequences

Self may request additional options or clarification while consulting Identity, but the framework must not silently provide an ideal solution outside the current cognitive system.

## Flexible implementation

Proposal generation, representation, and deliberation mechanisms remain open.
