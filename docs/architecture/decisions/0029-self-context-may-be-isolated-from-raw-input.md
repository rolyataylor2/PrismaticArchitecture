# ADR 0029: Self Context May Be Isolated From Raw Input

Status: Superseded by ADR 0033.

## Decision

The current canonical model requires Self to receive mediated internal representations rather than raw external input.

## Reason

This supports Part-mediated perception experiments and a potential boundary against direct manipulation of final decision contexts by hostile external language.

## Consequences

Perception and/or Parts may mediate external information before Self integration. Parts are not thereby trusted or objectively correct.

## Flexible implementation

Security mechanisms remain open, but the canonical WorldState isolation boundary is decided by ADR 0033.
