# ADR 0016: Subjective Memory Belongs to Parts

## Decision

Subjective autobiographical memory is primarily held by Parts rather than one canonical internal Agent transcript.

## Reason

Parts interpret experience through different missions and beliefs. Different memory representations preserve meaningful cognitive disagreement and perspectival development.

## Consequences

Different Parts may remember the same external event differently. Parts do not automatically access each other's memories. The current Self perspective may reconstruct events by consulting several Parts and accessible external records.

## Flexible implementation

Storage, indexing, encoding, and retrieval mechanisms remain undecided.
