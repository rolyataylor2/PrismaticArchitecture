# ADR 0106: Fourteen default primitives

Status: Accepted
Date: 2026-10-01
Extends ADR 0104's factory vocabulary.

The newborn defaults comprise seven appraisals (Novel, Unexpected, Pleasant, Aversive, Agent caused this, Uncertain, Addressed to me) and seven action tendencies (Repeat this, Stop this, Look closer, Seek interaction, Respond, Signal uncertainty, Seek information). Agent caused this registers apparent responsibility of another intentional entity, without assuming motives or certain causation.

Uncertain registers ambiguity; Signal uncertainty advocates communicating missing knowledge; Seek information advocates asking to reduce a specific gap. Addressed to me registers directed communication; Respond advocates a basic grounded response. Appraisal does not require the corresponding action tendency to activate or win. Self selects existing bids; primitive generation supplies speech before selection, and external execution enacts it. Expression may vary without introducing a new primitive for each phrase.

No emotion or relationship primitives are added. Learned psychological specificity remains with Parts. Existing IDs retain continuity; four new IDs are appended. New/unconfigured Agents and Reset all use the fourteen defaults. Saved researcher configurations and historical records remain intact; no automatic migration overwrites edits or resurrects deleted primitives.

Existing scoring, thresholds, memoryless cognition, provider routing and world-blind Self boundaries remain unchanged. Factory activation instructions and per-primitive thought/bid instructions reflect these distinctions; no inference task or Settings prompt entry is added.
