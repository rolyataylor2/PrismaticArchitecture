# ADR 0128 — One online cognition loop, retained consolidation

Status: Accepted

The researcher wants to keep consolidation and remove the previous system from the main cognition loop. Online cognition always uses ADR 0126 constructed perspectives. Persistent-population activation, vector candidate filtering and memory-owner discovery are removed from the application runtime. There is no alternate online architecture selector.

The existing stored `architecture` field and SDK seed-profile argument remain compatible with offline Part-development experiments. They select the retained consolidation profile only; they never select an online loop. Researcher controls name this distinction explicitly as a consolidation profile. Existing structural consolidation, formation, splitting, merging, reconsolidation and replay facilities remain unchanged. New constructed consolidation continues learning dispositions and reinterpreting episodes without reviving retired instances.

Online activation scores only current constructed working instances and primitives. Accessible supporting/contrary episodes enter their defined contexts. Constructed pending predictions can be evaluated after retirement, using original-thread evidence. Forecasts belonging to non-instance legacy Parts remain historical/offline records, so their former permanent-Part learning helpers cannot enter online cognition. World-blind Self, Identity guidance and external execution remain unchanged.

Historical regression fixtures may preserve the old runtime and candidate filtering under `tests/` to test earlier contracts and retained offline consolidation. Production packages must not import them; they are not application capabilities. Tests of the application cognition path must use the actual runtime, including an Agent bearing a legacy profile and obsolete activation settings, to verify that neither can restore the former loop.

The online cognition factory prompt describes temporary models; the former PersonaGPT factory branch is removed. Offline development prompts remain available. Numeric permanent-Part prediction learning helpers remain for historical/offline compatibility but are never reached by new working instances.
