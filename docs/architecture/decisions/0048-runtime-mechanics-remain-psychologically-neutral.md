# ADR 0048: Runtime Mechanics Remain Psychologically Neutral

## Decision

Persistence, indexing, scheduling, versioning, caching, and patch application are runtime responsibilities. Psychological meaning remains in cognitive inference.

## Reason

Mechanical convenience must not turn arbitrary thresholds or storage operations into theories of mind.

## Consequences

Runtime validates shape, permission, and mechanical consistency. Cognitive systems propose semantic changes and lifecycle meaning.

## Flexible implementation

Storage, indexing, validation, and orchestration mechanisms remain replaceable.
