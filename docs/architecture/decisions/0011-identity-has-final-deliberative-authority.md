# ADR 0011: Identity Has Final Deliberative Authority

Status: Superseded by ADR 0034.

## Decision
Historically, this ADR described Identity as the final chooser. It is retained for history but superseded by ADR 0034, which assigns active selection to Self while Identity remains the persistent reference.

## Reason
Historically, this record assigned active choice to Identity. The current model instead treats Identity as persistent self-definition consulted by Self.

## Consequences
Historically, this ADR also described Identity questioning Parts before choosing. Under ADR 0034, Self questions Parts and chooses while consulting Identity. The Executive remains non-sovereign.

## Flexible implementation
The historical mechanism is no longer current authority; Self implementation remains experimental within ADR 0034.
