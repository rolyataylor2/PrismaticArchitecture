# ADR 0180: Sleep prediction evidence reconciliation

Status: Accepted implementation target, 2026-10-23. Source: [researcher thread](../../development/METACOGNITIVE_LEARNING_THREAD_SOURCE.txt).

Extends ADRs 0138/0160. The final thread conclusions supersede its early suggestions of perceptual traces, dedicated metacognitive dispositions and primitive-generated predictions. Existing current-profile activation and asynchronous cognition remain unchanged; no extra activation pass is added. Primitives remain outside current online cognition.

## Ordinary cognitive strategy learning

Ordinary Part predictions may concern attention, encoding, recall, interpretation, deliberation or the cost of reflection, as well as external states and consequences. Existing temporary prediction-bound dispositions express contextual activation, memory relevance and tracked distinctions. Their descriptions guide ordinary independent activation and memory accessibility; they cannot change runtime mechanics, gain private-state access, execute recall programs or bypass Self. No seeded metacognitive controller or special prediction category is required. Pretrained knowledge can suggest a strategy but cannot establish its personal use or success.

Corrective feedback is ordinary experience. An agent may learn from being told it missed an opportunity without inventing a memory of the original event. Counterfactual benefits remain hypotheses until supported by experienced evidence. Current thought history and mediated cognitive products remain subjective; researcher audit history is not autobiography. Self remains world-blind.

## Sleep evidence reconciliation

Before normal current-profile structural reconciliation, sleep can review open predictions against selected existing subjective memories. Historical retrieval is bounded and relevance-based, using the prediction capsule and temporary relevance definitions. No raw WorldState archive, private Part snapshot, hidden environmental truth or new perceptual trace store is supplied. Selection respects Agent ownership, thread attribution and deleted-memory boundaries. Inputs are captured before synthesis or memory reinterpretation writes.

Each assessment preserves prediction ID/version, selected memory IDs/versions and their chronology. Distinguish prospective validated/invalidated evidence, retrospective support/challenge, obsolete context and unverifiable evidence. A later report about an earlier event does not establish that the event occurred after prediction formation. Mixed, uncertain and counterfactual evidence cannot be upgraded to prospective success merely because the memory was written later. Model interpretation does not establish authoritative world truth.

Retrospective support/challenge is an evidence annotation, not a fabricated waking outcome, forced closure or correctness reward. Insufficient evidence can leave an investigation open. Explicit obsolete closure preserves source versions and ends associated temporary scopes through existing lifecycle rules. Any prospective closure requires admissible later occurrence evidence and preserves causal qualification. Revisions preserve original claims and temporary scope history. New subjective interpretations use first-person language.

Avoid reviewing every prediction against every memory every sleep. Review eligible open predictions with changed selected evidence or changed prediction versions; persist reviewed fingerprints, including abstentions. Bound predictions and memory candidates per sleep, expose defaults/ranges and behavioral effects in existing sleep settings, and preserve deferred work for a later sleep. Provider failures remain infrastructure failures and do not count as unverifiable cognition.

## Consolidation and evidence strength

Reconciliation results feed existing offline disposition learning with validated source citations. They do not introduce an alternate institutionalization path. Durable descendants still require ended source investigations and repeated recorded ordinary usefulness under existing policy. Retrospective support, imagined benefit, coactivation or a single correct prediction alone cannot satisfy usefulness. Existing generalization, specialization, split, merge and archival remain conservative and versioned. A temporary disposition may remain eligible while its prediction remains open without activating.

## Required integration and verification

Keep schemas, provider routing, editable factory prompts, task descriptions/previews, persistence, settings and researcher inspection synchronized. Display evidence relationship, chronology, uncertainty and source lineage. Preserve current online outcome checks and existing saved state. Add sourced Simulation Tests for correction-driven strategy hypotheses, historical support/challenge, prospective comparison and no-evidence controls using fresh Agents and the ordinary pipeline. Deterministic fixtures verify boundaries and lifecycle only; configured-model observations must identify inconclusive/nonemergent results honestly.

Implementation completion requires runtime/persistence tests, prompt/provider contract coverage, settings verification, runnable experiments and a requirement-level completion audit. This decision does not claim those deliverables are finished.
