# ADR 0027: Not Every Action Requires Self Deliberation

Status: Superseded by the canonical fast-versus-deliberative Self selection model.

## Decision

The historical concern was avoiding unnecessary lengthy debate. The current solution is fast Self selection, not behavior outside Self.

## Reason

Routine, practiced, familiar, and highly certain behavior need not require explicit reflective debate each time.

## Consequences

Both fast and deliberative behavior pass through Self. “Automatic” means minimal Self deliberation, not a bypass. Behavior can become subject to deeper reflection later.

## Flexible implementation

No certainty, dominance, familiarity, or conflict threshold has been selected.
