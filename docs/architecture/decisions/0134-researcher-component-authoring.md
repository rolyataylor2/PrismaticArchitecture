# ADR 0134: Researcher component authoring

Status: Accepted, 2026-10-04.

The researcher component menus support explicit creation of dispositions, subjective memories and predictions. These are privileged starting-condition edits, not organic learning, therapy, simulation experiences or cognitive actions. Saves append versioned records with researcher origin. Existing online cognition and offline consolidation remain unchanged.

Memory and prediction creation requires an existing owning Part and an existing Agent cycle selected for provenance. A prediction's cycle must belong to its constructed owner's original thread. Each Part still carries at most one open prediction. Referenced disposition prerequisites must belong to this Agent. Manual creation never fabricates a world event, activation, outcome, evaluation or developmental evidence.

Smart creation for memories and predictions uses a single researcher-authoring task with only the researcher's explicit description and requested component kind. It receives no WorldState, Identity, private Part state or audit archive. The model proposes editable prose fields, not IDs, ownership, lifecycle or authority. The researcher reviews the draft and explicitly saves through the same validated creation API. Failure preserves existing records. The task is editable and previewable in Settings → Prompts, routed through the selected authoring model.

Search, sort and filter are researcher display operations. They neither alter stored ordering nor influence activation, recall or cognitive selection.
