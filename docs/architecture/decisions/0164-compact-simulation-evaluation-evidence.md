# ADR 0164: Compact simulation evaluation evidence

Status: Accepted, 2026-10-13. Researcher request: repair oversized evaluator packets and reassess the preserved longitudinal dream.

Extends ADR 0141. Researcher-only packaging retains exact relevant object versions once, with content hashes and original stage/snapshot citation paths. Stage products, observations, controls, contradictions and missing prerequisites remain explicit. Objects used, checked, recalled or changed during a dream are selected mechanically; unchanged unused inherited biography and redundant source/copy snapshots are excluded. No model summarizes away contrary evidence. Only predictions involved in the run generate alignment checks; historical original assessments remain unchanged.

Full immutable source evidence remains saved for citation inspection. Assessments additionally preserve the exact compact packet/hash sent to the evaluator. Runtime validates citations against both the frozen source and the content actually supplied. Settings previews and factory descriptions use that packet. These external research records never enter Agent cognition or confer learning authority.

The existing 750,000-character request bound remains. An oversized combined request falls back to separate criteria, with exact per-criterion request/packet/status records. Alignment criteria can narrow to their cited prediction while preserving run context. A criterion still exceeding the bound is explicitly inconclusive for insufficient supplied evidence, with no model call or silent truncation. Provider and contract failures remain infrastructure failures. Prior failed assessments and complete run state are preserved when reassessing.
