# ADR 0177: explicit authored Agent initialization

Status: Accepted
Date: 2026-10-22

## Decision

SDK callers may explicitly supply a validated, source-attributed Identity seed when creating a fresh Agent. Omission preserves the existing demo preset. An explicit seed replaces rather than merges demo Identity and does not seed demo persistent Parts, memories, dispositions, predictions, bids or outcomes. Generated identifiers remain fresh; source records distinguish authored starting conditions from subsequent learning. Invalid input is rejected before creation. Identity Trait roles retain ADR 0101 access semantics; authored autobiographical text is not lived memory or world truth.

Simulation Test definitions may declare the same initialization. It is applied only when a fresh isolated test Agent is created, before starting configuration capture. Dreams preserve their existing base; exact reruns/forks still restore their captured starting state. Ordinary WorldState → Parts → world-blind Self → external execution remains unchanged. This is researcher authoring, never an environment's authority to edit a living Identity. No new inference task, prompt, calibrated numerical psychological mechanism or automatic motive is introduced.

Add paired body-sensation cases comparing explicit general versus bodily-wellbeing self-definition under hungry/no-hunger vignettes. These are authored priors, not emergent motivation, clinical cases or proof of human psychology. Executive remains disconnected in sidebar cases; separate Coupler live trials test physical realization. No expected bid, activation or winner is prescribed. History/skills must come through separately attributed ordinary experiences; this seed supplies neither fabricated successful actions nor universal knowledge.
