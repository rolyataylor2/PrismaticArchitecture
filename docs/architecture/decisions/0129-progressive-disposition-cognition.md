# ADR 0129: Progressive disposition cognition

Status: Accepted, 2026-10-03. Requested by the researcher.

Refines ADR 0126 and supersedes same-cycle recursive scope expansion and ADR 0097 separate prediction formation for production cognition. Historical/offline fixtures retain their previous contracts.

Only roots and children whose entity-bound prerequisites activated on the preceding completed thread cycle are eligible. Eligibility is frozen before scoring; current scores never unlock descendants in the same cycle. Reclassification/disappearance closes a scope. Broad and specific perspectives may coexist and think independently; construction receives all active bindings and must preserve their distinct concerns.

Memory accessibility is scored separately for each active disposition/entity binding against the immutable WorldState and thread steering. Selected sufficient subjective episodes are delivered chronologically, never rewritten into short retrieval snippets. Each active Part receives one independent cognition generation per cycle, including inferred beliefs, appraisal, affect, thought, optional local goal, optional prediction and optional bid. No separate prediction gate or generation runs in production. At most one unresolved prediction per instance remains enforced. Working belief/affect changes are versioned temporary state, never a lifelong personality.

Self remains world-blind: the requested scene context reaches Self through Part appraisals and forecasts, never raw WorldState. Identity guides selection and external execution retains authority. Deliberation remains a separate mediated process.

Memory encoding must preserve enough context, perceived details, subjective meaning, affect, relevant thought/prediction/action/outcome/evaluation, learning and uncertainty to reconstruct significance without objective logs. Fields may be expressed in prose; not every Part or cycle warrants a memory. Prediction attention is temporary and takes effect next cycle; durable attention is learned offline from experienced evidence. Research audit retention is distinct from bounded cognitive event access.

Durable learning may also use selected salient subjective episodes without a prediction. A cited prediction must be resolved and linked to the supplied episode. Consolidation may version existing dispositions to strengthen, weaken, specialize, generalize or deactivate them; it never rewrites historical versions.
