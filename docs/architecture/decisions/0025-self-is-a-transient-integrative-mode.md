# ADR 0025: Self Is a Transient Integrative Mode

## Decision

Self is temporary whole-agent integrative cognition rather than another persistent mission-bearing entity. Identity, Parts, memories, and developmental state persist as appropriate.

## Reason

Full integrative reflection is needed only when circumstances require it. Treating Self as an inference mode avoids duplicating persistent state owned elsewhere.

## Consequences

Self context is assembled from relevant persistent and current information. Persistent consequences are written to appropriate domain systems.

## Flexible implementation

Runtime representation and episode duration remain open.
