# ADR 0139: Soft disposition activation associations

Status: Accepted, 2026-10-08. Researcher request and source: https://chatgpt.com/share/6ac7cdd2-3d4c-83e8-aee2-1cb226efc55d

Supersedes hard disposition prerequisite eligibility in ADRs 0126/0133/0136/0138. All other immutable snapshot, Part continuity, temporary scaffold lifespan, admission, world-blind Self and offline institutionalization boundaries remain.

Each disposition may carry a list of activation associations. Each entry identifies either a keyword/phrase or another disposition, with a contributing or inhibiting effect. Associations express contextual sensitivity, never truth, emotion, bid strength, execution sequence or mandatory requirements. Existing cues still describe direct attention. No numeric psychological weights or conjunction engine is added by this request.

All live, otherwise eligible scopes receive independent direct JEV activation against the same experienced WorldState. No disposition waits for a parent's previous-cycle activation. Freeze those baseline scores before independently reevaluating associated targets once with their own baseline and referenced baseline scores. Keywords are interpreted contextually against the same snapshot; quoted, negated or imagined words are not automatically facts. The second pass uses only frozen direct scores, including below-threshold values; final association effects cannot feed back, recurse or unlock additional passes. Circular links are allowed without circular computation. Missing, inactive, ended or deleted sources supply no signal. Recruitment uses the same two-pass process including direct scores for participating sources, but generates only nonparticipating scopes. No private Part state is shared.

Final scores determine activation under ordinary thresholds and subsequent temporary admission budgets. Inspection preserves direct and associated judgments separately. Usage, prediction evidence and ordinary-use statistics use final judgments. Offline learning retains direct scores separately to distinguish externally grounded coactivation from association-induced participation; coactivation alone cannot automatically strengthen links or authorize durable learning. Online evidence attachment remains nonsemantic. Existing evidence-validated offline operations can add/remove explicit associations or refine association lists, preserving versions and lineage.

Legacy prerequisites remain readable and historical bodies stay unchanged. When no explicit association list exists, legacy prerequisite IDs are interpreted as contributing disposition associations. An explicit list (including empty) replaces that compatibility view. New editor writes use associations and clear legacy prerequisites. Legacy dependency reconciliation operations remain compatibility aliases for contributing links, never gates.

The factory activation prompt and Settings task description cover both phases under the existing activation task; no provider routing task is added. Researcher authoring validates same-Agent references and rejects self-links. Runnable Simulation Tests compare contribution, inhibition, direct-only controls and circular links through ordinary cognition on isolated Agents. Mock results validate plumbing only; configured observations require semantic review. Automatic Hebbian learning, decay, amplification weights and recurrent dynamics remain experimental questions rather than silently implemented architecture.
